# Small Steps 项目测试框架文档

## 概述

本文档为 Small Steps 项目各组件提供统一的测试框架和测试用例规范。

## 测试策略

### 测试金字塔
- **单元测试** (Unit Tests)：测试单个函数或类的功能
- **集成测试** (Integration Tests)：测试多个组件之间的交互
- **端到端测试** (E2E Tests)：测试完整的用户流程
- **性能测试** (Performance Tests)：测试系统性能指标

### 测试覆盖范围
- 核心业务逻辑
- API 接口
- 数据库操作
- 前端组件
- 硬件交互
- 语音识别功能

## 测试用例编写规范

### 命名规范
- 测试类：`{被测试类名}Test`
- 测试方法：`should{期望行为}When{测试条件}`

### 测试结构 (AAA 模式)
- **Arrange** (准备)：设置测试数据和环境
- **Act** (执行)：执行被测试的代码
- **Assert** (断言)：验证结果是否符合预期

### 示例
```java
@Test
void shouldReturnUserWhenValidIdProvided() {
    // Arrange
    Long userId = 1L;
    User expectedUser = new User();
    expectedUser.setId(userId);
    
    when(userRepository.findById(userId)).thenReturn(Optional.of(expectedUser));
    
    // Act
    User actualUser = userService.getUserById(userId);
    
    // Assert
    assertThat(actualUser).isNotNull();
    assertThat(actualUser.getId()).isEqualTo(userId);
}
```

## 持续集成

所有测试将在 CI/CD 流程中自动运行：
- 代码提交时运行单元测试
- PR 创建时运行完整测试套件
- 主分支合并时运行性能测试

## 测试执行命令

### smallsteps-api
```bash
cd smallsteps-api
mvn test                    # 运行所有测试
mvn test -Dtest=*UnitTest  # 只运行单元测试
mvn verify                  # 运行测试并生成覆盖率报告
```

### smallsteps-ui
```bash
cd smallsteps-ui
npm run test:unit          # 运行单元测试
npm run test:e2e           # 运行 E2E 测试
npm run coverage           # 生成覆盖率报告
```

### smallsteps-app
```bash
cd smallsteps-app
npm run test:unit          # 运行单元测试
npm run test:component     # 运行组件测试
```

### xiaozhi-esp32-server-java
```bash
cd xiaozhi/xiaozhi-esp32-server-java
mvn test                    # 运行所有测试
mvn verify                  # 运行测试并生成覆盖率报告
```
