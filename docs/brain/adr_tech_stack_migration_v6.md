# ADR: V6 重大重构与技术栈演进 (Spring Boot + UniApp)

## 状态
**已接受**

## 上下文
在“小步(Small Steps) - ADHD 行为干预辅助系统”的诸多基础迭代版本中，系统尝试采用 Python (FastAPI) 及实体物联网(IoT)微控制器等方案来构建。但在后续面向产品闭环和家庭教育的深入研究后发现，单凭简单的效率工具或独立的硬件玩具，在应对多动症儿童（ADHD）极弱的持续专注力和极高的挫折感时，其体系化支撑力显著不足。此外，原有的架构在面临高频多端状态同步和全家（监护人网）权限拆分时，维护成本较高。

## 决策
为了更好地服务于“家庭动力学重塑”和“减认知负荷”的核心设计哲学，我们在 V6 版本做出了巨大的架构体系跨入：
1. **后端工业化演进**：将底座全面迁移至 **Java 生态的 Spring Boot 3 + MyBatis-Plus**，借助 **[[Sa-Token]]** 实现极度灵活的（管理员、家长、儿童）多级越权防线，使用 **Redis** 支撑会话认证和接口高频防抖拦截。
2. **前端架构重构**：网页端和服务端剥离，移动终端基于跨平台框架 **[[UniApp]]** 打通。通过引入 Vue 3 (Composition API) 结合 **Pinia** 缓存技术实现多模式路由鉴权状态管理；在界面语言上抛弃复杂设计，重构基于 **TailwindCSS** 的“原子化、0认知负荷”极简 UI 哲学。
3. **基于大模型 (LLM) 的情绪辅助**：引入后端异步拉取/解析 AI 模型的能力，针对每一天产生的行为打卡日志进行深度计算与寄语生成，极大释放干预者的心力。

## 影响
* **优势**: 大幅提升了后端系统的工业级可靠性和性能峰值并发（满足秒杀级打卡结算场景）；通过彻底地技术栈换血，充实了学术论文工程部分的展示深度与含金量；技术架构完全匹配了现代 B/S 分布式演进趋势。
* **挑战**: 原型设计的全盘翻印要求在极短时间内完成所有接口时序图重绘与章节理论的润色缝合。
