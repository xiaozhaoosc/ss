# 儿童端辅助活动占位说明 [[Child-Activity-Placeholders]]

## 1. 背景
在儿童首页 (`pages/child/home/index.vue`) 的任务区域下方，设计了两个卡片入口：**艺术课 (Art Class)** 和 **游戏时间 (Game Time)**。

## 2. 功能定义
这两个模块属于“次要操作 (Secondary Actions)”，其设计初衷是为 ADHD 儿童提供任务完成后的非药物干预调节。
- **艺术课**: 预想为绘图、色彩心理表达等低认知负荷活动。
- **游戏时间**: 预想为短暂的体力活动建议或轻量化游戏奖励。

## 3. 实现现状 (v1.2.0)
- **状态**: **仅 UI 实现 (Placeholder Only)**。
- **源码分析**:
    - 在 `index.vue` 中硬编码了两个 `link-card`。
    - 点击事件绑定到 `handleQuickLink`。
    - 该方法目前仅调用 `uni.showToast` 显示 "Open 艺术课/游戏时间"，未进行实际页面跳转。
- **缺失项**:
    - 尚未在 `pages.json` 中定义相关页面。
    - 尚未开发对应的业务组件或逻辑。

## 4. 后续建议
- 在家长端增加对这两个模块的可配置性（例如：允许家长设置游戏时间的长短）。
- 在儿童端实现基于星星代币的“购买/解锁”逻辑。
- 增加“敬请期待” (Coming Soon) 的视觉标记，避免用户混淆。
