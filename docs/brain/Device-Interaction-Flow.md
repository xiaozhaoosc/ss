# Device Interaction Flow (设备交互流与原则)

硬件终端 (ESP32-S3 设备) 的交互设计受到极端的硬件资源限制，但这种限制刚好是抑制 ADHD 儿童被“过度刺激”的优势护城河。

## “少即是多”交互准则

### 1. 屏幕边缘化 (Degradation of Display)
在此设备中，**屏幕是辅助，灯光和声音才是主角**。
对 ADHD 孩子而言，文字解析会占据大量认知负荷（Cognitive Load）。
- **光语 (Light-Language)**: 通过 WS2812B 的颜色和呼吸频率（快/慢）表示时间进展。
- **声语 (Sound-Language)**: 环境白噪音或低频提示音。

### 2. Focus Mode (极致专注流)
执行任务时，微型屏幕不要放置冷酷的倒计时秒表（容易引发焦虑症）。
**替代设计**: 
- 能量球消耗反馈
- 像素风沙漏 
- 灯带渐进熄灭

### 3. 抗拒状态与优雅降级 (Graceful Degradation)
当出现“情绪崩溃”场景下的暴力抗拒按下错误按键时：
- **物理韧性**: UI 操作**不存在死胡同**。
- **降级陪伴**: 如果系统检测到孩子3天未完成任务，系统转入**被动陪伴模式**（单纯播放呼吸灯），而不进行任务提醒或警告，解除焦虑对立锁定。

## “四大物理按键”隐喻
- **UP / DOWN**: 用于鱼眼风格 (Fisheye) 的轻量级任务翻页。
- **OK**: 超大视觉反馈的“确认/成功”行为。
- **BACK**: **高容错键**，误触绝不能导致任务强退（必须配合 2 秒防误触长按或重力组合确认）。
