## [Decision_Log]
### ADR-019: 生产环境监控组件的“按需开启”原则
- **背景**: 发现生产环境下 `SmallSteps` 应用频繁尝试向 `localhost:9090` 注册 Admin 实例，导致 I/O 错误及 ConnectException 日志爆炸。
- **决定**: 在 `application-prod.yml` 中默认关闭 `spring.boot.admin.client` 和 `snail-job`。
- **方案**: 采用 `${SPRING_BOOT_ADMIN_CLIENT_ENABLED:false}` 占位符，允许通过 Docker Compose 环境变量在需要时无代码侵入式开启。

### ADR-018: 基于命名空间的 Sass 全局变量注入策略
- **背景**: 在迁移至 `@use` 时，简单的 `as *` 会导致在 `.vue` 文件 `@use` 同样包含注入变量的 `.scss` 文件时产生命名冲突。
- **决定**: 在 `vite.config.js` 中将注入改为有命名空间的模式：`@use "@/uni.scss";`。
- **影响**: 彻底解决了变量碰撞问题，同时保持了代码的现代性。由于当前业务代码未直接使用 Sass 变量，此变更为零风险。

## [Inbox_&_Inspirations]
- **Sass 兼容性**: 发现 Uni-app 的 Vite 插件不支持在 `additionalData` 中使用 JavaScript 函数。
