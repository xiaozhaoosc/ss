# 2026-04-24 调试与修复记录

## 1. 异常与错误反思 (Project Reflection)
今天在实现与对接过程中，出现了较高频的错误和异常。核心问题在于 **“跨端/跨层同步遗漏”** 与 **“验证不足”**：
- **前端路由配置冲突**：在 `router/index.ts` 中重复写了原属于 `permission.ts` 的 `beforeEach` 鉴权与 404 拦截，导致 `router.addRoute` 之前路径就被截断为 404。这暴露了我们从模板移植代码或快速生成代码时，未充分梳理全局生命周期。
- **SASS 大括号溢出**：对 `.vue` 文件样式（`timeline-item.vue`）进行修补时，局部括号多余导致整个项目打包/编译崩溃（unmatched `}`）。
- **数据库字段与 Entity 不同步**：为 `ss_task_log` 引入了 `autonomyScore`（自主性评分），Java 实体层已添加，但忘记在数据库表结构中补充对应的 `ALTER TABLE` 语句，直接引发 `BadSqlGrammarException`。

**后续改进约定 (The Rituals)**：
执行 `Directive` 后，严格遵循 `Human 3.0 Protocol` 中的 **验证为王 (Validation)** 准则。前后端联调前必须先在底层确保数据表的一致性，凡是涉及到 Entity 增减字段的，必须输出 SQL 并验证。

## 2. 补丁 SQL 记录

修复 `ChildTaskMapper.java` 报错所需的 SQL（向 `ss_task_log` 增加 `autonomy_score` 列）：

```sql
ALTER TABLE ss_task_log ADD COLUMN autonomy_score INT2;
COMMENT ON COLUMN ss_task_log.autonomy_score IS '自主性评分 (1-5)';
```
