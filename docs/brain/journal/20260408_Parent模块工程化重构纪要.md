# 📝 Parent 模块底层架构抽离与 CRUD 自动化结案

> [!NOTE] 触发背景
> 作为 "Small Steps" 行为辅助系统的家长核心控制面，任务发布、奖励设定与家庭契约管理是整个生态跑通的最关键领域。为了解除 `smallsteps-admin` 核心单体的过度臃肿，我们在本次迭代中正式抽离并打通了 `smallsteps-parent` 独立业务子模块。

## 🏛️ 结构决策与自动化细节

通过解析并利用自动化生成底座，我们在 15 分钟内实施了一次 2000+ 行级别的前后端骨架“重构与降维打击”。

### 1. 独立限界上下文隔离 (Bounded Context)
引入了全新的 Maven 依赖树子域：`smallsteps-parent-5.3.0.jar`，并以挂载模式集成到主容器 `smallsteps-admin/pom.xml` 中。此举标志着业务逻辑开始解耦，专门服务于“家长”心智模型。

### 2. 核心三角业务落地 (Core Triad)
系统级地自动生成了下述三足鼎立的业务实体的全量架构（涵盖 Vo, Bo, Mapper(.xml), Service, Controller）：
- **ParentTask (`ss_parent_task`)**: 粗细粒度行为任务拆解配置区
- **ParentReward (`ss_parent_reward`)**: 去通货膨胀化的成长反馈激励库
- **ParentContract (`ss_parent_contract`)**: 家庭三方（双亲及子）契约背书实体

### 3. 工程化防线预置
18个端点全部严格嵌置了权限拦截锚点（如 `parent:task:list` 配合 Sa-Token）、JSR-303 参数自检与逻辑软删除。

## ⚠️ 隐患与真实细节 (The Gotchas)

1. **路由与测试冲突风险**：从目前的终端活跃状态表明（正在跑 `auth/code` curl 测试），将子模块接口注册入主系统时，必须高度警惕 404 及 Swagger `doc.html` 对于该新建分组 API 的未能成功扫描（ComponentScan 扫描范围盲区）。
2. **字典一致性**：`status`、`difficulty` 等字段高度依赖于 UI 层与后端的字典约定。必须在进入 Vue `smallsteps-ui` 组件挂载前，核对后台字典表配置。

> *“不再一行行手写 CRUD，才是我们将脑暴留给 ADHD 干预设计的核心防线。”*
