# 2026-04-25 技术周报 (Small Steps)

## [Morning_Briefing]
- **核心焦点**：看板 500 报错修复、统一请求链路迁移、AI管理模块增强。
- **状态现状**：App 端频繁出现 401 和 500，且报错信息被 Toast 截断，排查极其困难。AI 模块配置依赖热部署需求。

## 关键突破

### 1. 统一请求链路 (`request.ts`)
- **动作**：废弃 `request.js`，全面转向类型化的 `request.ts`。
- **创新点**：引入了 **“强力正则解析器”**。针对 App 环境中可能出现的 `Status 500 {"code":500...}` 这种复合字符串，使用 `match(/\{[\s\S]*\}/)` 自动提取有效的业务 JSON。
- **UX 优化**：针对业务错误，实现了从 `Toast` 向 `Modal` 的自动降级逻辑。长消息（如 MapStruct 转换异常）不再被截断。

### 2. AI 动态路由与管理闭环 ([[ADR_005_AI_Dynamic_System]])
- **数据驱动**: 激活了 `AiProviderController` 等全套后端接口，支持数据库管理 AI 配置。
- **UI 闭环**: 前端配套完成 `system/ai` 四大子模块（供应商/模型/提示词/路由）。
- **健壮性**: 实现了 Prompt 与路由的双重兜底机制。

### 3. AI 聊天逻辑深度重构 (Refactor)
- **动作**：彻底剥离 `ChildAIServiceImpl` 中的硬编码分支。
- **机制**：通过 `IAiService.chat` 接口，实现从数据库加载 `AI_CHAT` 场景路由。
- **Persona 注入**：在 `getFallbackPrompt` 中显式定义了“小步”AI 伙伴人格（活泼、鼓励、表情丰富），确保即使数据库配置失效，品牌形象依然一致。

### 4. 基础设施与连接性调试 (Infrastructure)
- **突破**：定位并复现了远程模型服务器（192.168.1.9）宕机以及备用服务器（10.8.0.1:8005）返回 HTML 导致的 JSON 解析异常。
- **测试协议**：建立了 `start_server.ps1` 启动脚本，强制依赖关键环境变量（DB/Redis/AI_KEY）。

### 5. 家长洞察 (Parent Insight) 看板闭环
- **聚合修复**: 重构 `ParentTaskServiceImpl` 逻辑，将 `status=3` (Light Up) 纳入所有统计（能力雷达、周/月报），确保点亮后的任务数据不丢失。
- **UI 导航**: 修复仪表盘“今日焦点”与“查看全部”跳转时 `childId` 丢失导致的空白页问题。
- **数据生态**: 运行 V8 版 SQL 脚本，为家长 ID `2035392423676469250` 生成了跨度 30 天、包含情绪热力、能力成长、任务日志的完整闭环数据，验证了看板的叙述化反馈能力。
