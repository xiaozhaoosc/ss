    - 针对 `smallsteps-admin` 执行 `mvn install` 确保主应用 jar 包包含最新的 common 依赖。
    - 使用 `java -Dspring.profiles.active=dev -jar` 重新拉起后端服务。
- **验证环节**:
    - 通过 `curl` 探测接口存活性。
    - 准备恢复 Playwright 自动化测试流程。

## 技术发现
- **运行时编译错误 (Unresolved compilation problems)**: 在某些特定的 Maven 构建环境下，代码即使存在编译错误（如 import 失败）也可能被打包并在运行时抛出 `java.lang.Error`。这通常意味着本地仓库中的 artifact 状态与源码严重不同步。
- **PowerShell 启动参数陷阱**: 在 PowerShell 中启动 Java 时，`-D` 参数建议使用单引号包裹以防止 shell 错误解析属性值。
