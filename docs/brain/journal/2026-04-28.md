## 关键任务
### 1. 时光机“未选择儿童”错误修复
- **发现问题**: 儿童进入 `pages/child/time-machine/index` 时，请求 `GET /child/ai/recent?childId=1002` 返回“未选择儿童”。
- **根因分析**: 后端 Controller 仅使用 `@RequestParam Long cid` 接收参数，而前端统一发送的是 `childId`。
- **解决方案**: 修改 `ChildAIController`, `ChildTaskController`, `ParentInsightController` 共 10 个 API，增加对 `childId` 参数的兼容。详见 [[ADR-011-Backend-Parameter-Mapping-Fix]]。
- **验证**: 修复后 `childId` 可正确绑定到 `finalChildId`，不再触发 500 报错。

### 2. 家长端周报 (Weekly Report) 加载异常修复 [DONE]
- **问题描述**: 访问 `/pages/parent/weekly-report/index` 时出现 500 错误，提示 `Failed to fetch dynamically imported module`。
- **根因分析**: 
  1. **依赖缺失**: `mp-html` 依赖在 `package.json` 中定义但未在 `node_modules` 中安装，导致 Vite 处理组件请求时返回 500。
  2. **语法错误**: `weekly-ai-report.vue` 中使用了无效的 Sass 深度选择器语法 `:deep(.dark) &`，触发了现代 Sass API 的编译错误。
- **解决方案**: 
  - 执行 `npm install mp-html` 补全依赖。
  - 重构 CSS，将 `:deep(.dark) &` 修改为标准支持的 `.dark &`。
  - 为 `weekly-ai-report.vue` 的 `formattedContent` 增加空值保护，增强健壮性。
- **验证**: 页面已可正常加载并展示 AI 深度洞察内容。
