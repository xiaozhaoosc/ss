### 3. API 404 故障修复与路径解耦
- **故障排查**: 发现 `/child/ai/emotion/trend` 等接口由于强制 `childId` 路径变量导致 ID 缺失时直接 404。
- **重构方案**: 采用可选路径变量 + 查询参数的兼容性方案（`@PathVariable(required = false)`），统一由 `finalChildId` 逻辑处理，极大提升了前端接入的容错率。
- **涉及 Controller**: `ChildAIController`, `ParentInsightController`, `ChildTaskController`。

### 4. 解决 Lombok 跨模块继承编译冲突
- **问题**: `ParentTaskServiceImpl` 无法识别 `ParentTask` (继承自 `BaseEntity`) 的属性访问器。
- **绕过方案**: 鉴于 Lombok 在多模块 Maven 系统中的不稳定性，将关键映射逻辑重构为使用 `BeanUtil.copyProperties`。这不仅解决了编译报错，还降低了业务层与持久层实体的硬编码耦合。
- **经验沉淀**: 后续公共实体若需跨模块共享，应确保基类模块已正确执行 `mvn install` 且注解处理器版本一致。

### 5. 自动化勋章激励引擎 (Badge System)
- **规则引擎**: 在 `ChildAchievementServiceImpl` 中内置了 `checkAndUnlockBadges` 逻辑，支持“早起鸟”、“恒心大师”及“星光熠熠”三类勋章。
- **系统钩子**: 将勋章检查挂载至 `ScoreServiceImpl.addPoints` 中，确保孩子每获得一次星星都能伴随一次荣誉感触达。
- **可视化**: 彻底重构勋章奖牌榜 UI，引入“收集手册”逻辑及锁定项置灰显示。相关笔记: [[Automatized-Achievement-System]]。
