# ADR: 侧边栏全动态化加载策略 [[20260408_Sidebar_Dynamic_Strategy]]

- **日期**: 2026-04-08
- **状态**: 已决定 (Accepted)
- **上下文**: 前端 `smallsteps-ui` 原本硬编码了大量 RuoYi 框架自带的样板菜单（如监控、工作流、Demo 等），不仅造成首屏加载视觉干扰，也违背了“4 大核心业务菜单”的产品目标。

## 方案选择

### 选项 A: 纯硬编码配置 (Static)
- **优点**: 稳定，不依赖后端接口。
- **缺点**: 修改不便，代码臃肿。

### 选项 B: 纯动态逻辑 (Full Dynamic)
- **优点**: 极致灵活，菜单完全由数据库控制。
- **缺点**: 若数据库配置错误（如删除了菜单管理），可能导致管理端“失踪”，造成死锁。

### 选项 C: 混合模式 (Hybrid) - **最终选择**
- **逻辑**: 将非核心业务的样板菜单从代码中移除，由 DB 驱动。**首页 (Dashboard)** 保留在代码中作为默认落地页和回退页，以保证系统稳定性。
- **决策点**:
  - 移除 `constantRoutes` 中的: `Monitor`, `Workflow`, `Tool`, `Demo` 组。
  - 将 `System Management` (系统管理) 业务化，由 DB 加载。
  - 保留 `首页` 路径 `/dashboard` 在代码中。

## 影响
- **代码库**: `src/router/index.ts` 缩减了约 60% 的代码量。
- **配置**: 任何菜单的顺序、图标和标题现在都可以直接在“菜单管理”页面进行实时调整，无需重启服务。
- **用户体验**: 侧边栏现在专注于业务核心，视觉噪音降低。
