## 🚀 快速开始

### 1. 安装测试数据

```bash
# 连接到 PostgreSQL 数据库
psql -U postgres -d smallsteps

# 执行测试数据脚本
\i docs/sqls/test_data_smallsteps.sql
```

### 2. 验证安装

```sql
-- 查看租户
SELECT tenant_id, company_name FROM sys_tenant WHERE tenant_id = 'SS0001';

-- 查看测试用户
SELECT user_id, user_name, nick_name FROM sys_user WHERE user_id >= 1000 AND user_id < 1010;

-- 查看儿童档案
SELECT id, nickname, star_balance, total_stars FROM ss_child WHERE tenant_id = 'SS0001';

-- 查看任务配置
SELECT id, title, star_reward, difficulty FROM ss_task WHERE tenant_id = 'SS0001';
```

## ⚠️ 注意事项

1. **密码安全**: 所有测试账号密码均为 `admin123`，仅用于测试环境
2. **租户隔离**: 测试数据使用租户 `SS0001`，与其他租户数据隔离
3. **ID 范围**: 测试数据使用的 ID 范围:
   - 用户: 1000-1099
   - 儿童: 10001-10099
   - 任务: 20001-20999
   - 奖励: 30001-30999
   - 兑换: 40001-40999
   - 星星: 50001-50999
   - 情绪: 60001-60999
   - 设备: 70001-70999
   - 家庭: 80001-80999
4. **幂等性**: 脚本支持重复执行，使用 `ON CONFLICT` 处理冲突
5. **时间数据**: 部分记录使用相对时间（如 `now() - interval '1 day'`），确保数据始终是"最近的"

## 🔄 重置测试数据

如果需要重置测试数据到初始状态，可以执行以下操作：

```sql
-- 删除测试租户的所有数据
DELETE FROM ss_family_member WHERE tenant_id = 'SS0001';
DELETE FROM ss_device WHERE tenant_id = 'SS0001';
DELETE FROM ss_emotion_record WHERE tenant_id = 'SS0001';
DELETE FROM ss_star_record WHERE tenant_id = 'SS0001';
DELETE FROM ss_reward_exchange WHERE tenant_id = 'SS0001';
DELETE FROM ss_task_log WHERE tenant_id = 'SS0001';
DELETE FROM ss_reward WHERE tenant_id = 'SS0001';
DELETE FROM ss_task WHERE tenant_id = 'SS0001';
DELETE FROM ss_child WHERE tenant_id = 'SS0001';
DELETE FROM sys_user_role WHERE user_id >= 1000 AND user_id < 1010;
DELETE FROM sys_user WHERE tenant_id = 'SS0001';
DELETE FROM sys_dept WHERE tenant_id = 'SS0001';
DELETE FROM sys_tenant WHERE tenant_id = 'SS0001';

-- 然后重新执行测试数据脚本
\i docs/sqls/test_data_smallsteps.sql
```
