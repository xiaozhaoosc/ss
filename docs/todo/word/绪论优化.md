# 1 绪论

## 1.1 研究背景
注意缺陷多动障碍（Attention Deficit Hyperactivity Disorder, 简称ADHD）是儿童及青少年时期最为常见的神经发育性障碍之一。流行病学研究表明，全球学龄儿童中ADHD的患病率约为5%至7%，且部分患儿的症状会延续至成年期[1,2]。其核心临床特征主要表现为与认知发育水平不符的注意力涣散、冲动控制能力弱以及显著的活动过度。尽管ADHD不直接影响个体的智力发育，但其对执行功能（Executive Function）——涵盖工作记忆、情绪调节、动机唤醒及规划组织能力——的广泛削弱，给患儿的学业表现、日常自理及社交适应带来了深远负面影响[3]。

在家庭与学校场景中，ADHD儿童常面临诸多困境。学业上，由于缺乏维持注意力的能力，课上容易走神，课后作业常伴随严重拖延，难以自主完成复杂任务；社交上，情绪调节能力的薄弱使得他们容易在同伴互动中产生冲突或遭遇孤立。长期的受挫体验极易诱发低自尊、焦虑及抑郁等继发性心理问题[4]。因此，如何构建科学、可持续的日常干预环境，辅助ADHD儿童逐步建立规律的生活学习节律，不仅是临床医学的重要课题，也是心理学、教育学与计算机科学交叉融合亟待解决的现实需求。

## 1.2 数字化行为辅助工具的应用价值
当前针对ADHD的临床干预主要包括药物治疗与行为矫正两大路径。药物治疗（如中枢神经兴奋剂）在短期内控制核心症状效果显著，但长期用药存在食欲减退、睡眠障碍等副作用隐忧，且部分家庭依从性不高[2]。以家长管理训练（PMT）为代表的线下行为干预被公认为具有更好的长期收益，但其实施高度依赖家长的执行能力与专业指导。现实中，家长在背负工作压力的同时，面对需长期高频重复的干预指令，极易产生“监督疲劳”与情绪耗竭，往往导致干预动作变形，甚至激化亲子矛盾[5]。

在此背景下，数字疗法（Digital Therapeutics, DTx）与数字化行为辅助工具展现出破局潜力。基于智能终端的软件系统具备全天候在线、反馈客观一致、数据精确可追溯的优势。将数字化工具引入家庭干预，可发挥双重效能：对儿童而言，通过游戏化的机制与即时正向多巴胺反馈，可有效弥补ADHD患儿内驱力不足的生理缺陷，将枯燥任务转化为具参与感的挑战；对家长而言，系统承担了部分机械的“提醒与监督”职能，作为客观的第三方介质，有效缓冲了亲子间的直接摩擦，使家长能重新回归“陪伴者”与“支持者”的温和角色。

## 1.3 面向ADHD的技术干预需求与缺口
尽管应用市场中效率管理、时间追踪类软件层出不穷（如各类番茄钟、日程表应用），但针对神经典型人群设计的通用工具在面对具有独特脑神经特征的ADHD患儿时，普遍存在严重的适配性问题：

（1）**界面认知负荷过高**：通用工具常追求功能大而全，界面信息密度高。对于工作记忆受限的ADHD儿童，繁杂的菜单与高饱和度色彩构成了严重的“认知噪音”，易引发抵触情绪。
（2）**任务拆解引导缺失**：ADHD儿童的核心痛点在于难以启动宏大或模糊的目标（如“写作业”）。多数工具仅提供单层任务记录，缺乏将复杂任务拆解为“微小、可立即执行”步骤的强制引导机制。
（3）**反馈机制缺乏包容性**：现有工具多以结果导向的“冷反馈”为主（如标红未完成任务）。ADHD儿童挫折耐受度低，负面结果的高亮展示极易触发其放弃行为；他们亟需的是对微小进步的即时肯定与失败时的温柔包容。
（4）**家庭系统协同断裂**：市面产品多局限于单机单用户使用，缺乏监护人端的数据观测与心理支持模块，无法在家庭微生态层面形成干预合力。

综上，领域内亟需一款基于ADHD认知特征深度定制、强调降低认知门槛、兼顾亲子双端协同的行为辅助系统。这也是本课题提出与设计的核心动因。

## 1.4 国内外研究现状与发展趋势
### 1.4.1 传统行为干预与认知疗法的局限
长久以来，认知行为疗法（CBT）及代币经济系统（Token Economy）被广泛应用于ADHD的行为重塑中[7,8]。然而，受限于时空条件，治疗室内的干预效果泛化至自然家庭环境时往往大打折扣。家长作为非专业执行者，难以长时间维持奖惩标准的一致性，导致干预效果难以为继。这凸显了引入标准化、自动化技术辅助手段以维持干预一致性的必要性。

### 1.4.2 数字疗法与应用程序在ADHD干预中的发展
随着移动互联网与AI技术的发展，数字化干预逐渐成为前沿热点。2020年，FDA批准了首款面向ADHD的处方级视频游戏EndeavorRx[6]，确立了游戏化数字干预的医疗合法性。在应用软件层面，欧美涌现出若干针对时间盲区和执行障碍的辅助工具。反观国内，ADHD相关应用多停留在量表测评或泛化育儿知识的知识付费阶段，缺乏针对本土教育环境深度打磨交互细节、且真正面向神经多样性（Neurodiversity）群体的全链路辅助工具。

### 1.4.3 现状总结与本系统的突破方向
利用数字化手段辅助ADHD家庭干预已成学界与业界的共识，但现有方案在深度定制与双端协同上存在显著空白。针对此现状，本课题研发的“小步（Small Steps）”系统力求在以下维度实现突破：
（1）**交互降噪设计**：全面贯彻“极简认知”理念，提供适合患儿的单线程任务专注视图，最大限度削减外在认知负荷。
（2）**AI驱动的动态干预**：引入大语言模型（LLM）进行智能任务拆解与基于历史数据的个性化寄语生成，实现从机械提醒向“懂孩子”的智能陪伴跨越。
（3）**家庭动力重塑**：通过前后端分离架构实现家长端、儿童端的数据实时互通，利用系统缓冲亲子矛盾，促使家长从“监工”向“教练”转型。

## 1.5 主要研究内容与论文组织结构
本论文以ADHD中小学生的日常行为习惯养成为核心，综合运用软件工程方法、移动端跨平台技术及人工智能接口，设计并实现了一套多角色协同的综合辅助系统。主要研究工作涵盖：
（1）结合认知心理学与行为干预理论，完成系统的需求分析与UI交互设计，提出并实现针对ADHD的专属专注模式。
（2）基于Spring Boot 3与MyBatis-Plus构建高可用的后端微服务，利用Sa-Token实现严密的多角色权限隔离与数据安全保障。
（3）基于UniApp与Vue 3技术栈，开发实现跨平台的移动端应用，创新性地运用Pinia实现“家长/儿童”双模式的无感动态切换。
（4）在业务流中深度集成大语言模型，构建基于患儿行为数据的AI智能寄语生成与任务拆解模块，增强干预系统的智能性。

本文的组织结构如下：
- **第1章 绪论**：阐述课题背景、数字化工具的应用价值、技术缺口及国内外研究现状，明确本文的研究目标。
- **第2章 系统分析**：从可行性、关键技术选型（Spring Boot, Vue 3, TailwindCSS等）及业务理论基础出发，详细进行系统的功能与非功能需求分析。
- **第3章 系统设计**：呈现系统的总体架构、多端协同机制、核心业务模块逻辑，并给出详尽的数据库实体关联与物理表结构设计。
- **第4章 系统实现**：结合核心代码，阐述后端服务、移动端双模式交互及管理后台的具体实现细节。
- **第5章 系统测试与结果分析**：设计多维度的测试用例，涵盖权限、业务流转及弱网兼容性，对系统运行效果进行评估。
- **第6章 总结与展望**：总结全文工作，分析现有不足，并对未来多模态感知接入与模型本地化等方向进行展望。
