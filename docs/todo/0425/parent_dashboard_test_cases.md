# Small Steps 家长端功能验收测试用例 (04-25)

## 1. 首页 Dashboard 数据校验
### 1.1 动态 SQL 数据渲染
- **前置条件**：已执行 `test_data_0425.sql`
- **步骤**：登录家长端首页，查看“执行时间轴”
- **预期结果**：
  - 时间轴显示今日模拟生成的任务名称（如：自主整理书包）
  - 任务状态显示为“已完成”（Light up）
  - 时间点与 SQL 生成的时间匹配

### 1.2 顶部统计信息
- **步骤**：观察 Dashboard 顶部的“任务总数”和“奖励总数”卡片
- **预期结果**：显示数字与数据库中 `ss_task` 和 `ss_reward` 表的总数一致（目前后端为 Mock，应显示 10 和 5）

## 2. 页面跳转与导航
### 2.1 今日焦点详情页
- **步骤**：点击首页“今日焦点”区域
- **预期结果**：跳转至 `/pages/parent/daily-focus/index`，显示今日任务详情、获得星星及奖励列表

### 2.2 执行记录列表页
- **步骤**：在“执行时间轴”区域点击“查看全部”
- **预期结果**：跳转至 `/pages/parent/exec-record/index`，以分页列表形式展示历史执行记录

## 3. 奖励管理功能
### 3.1 添加新奖励 (新功能)
- **步骤**：
  1. 进入“奖励设置”页 -> 点击“添加新奖励”
  2. 输入名称：`测试奖励_25`
  3. 设置星星：`50`
  4. 选择图标，点击“保存”
- **预期结果**：
  - 提示“保存成功”
  - 页面自动返回“奖励设置”列表
  - 列表末尾出现新增的 `测试奖励_25`

### 3.2 奖励状态切换
- **步骤**：在奖励列表中点击开关切换奖励状态
- **预期结果**：开关切换流畅，控制台或后台数据库 `status` 字段同步更新

## 4. 数据操作逻辑
### 4.1 删除执行记录
- **步骤**：在“执行记录”页面，点击某条记录后的“删除”按钮并确认
- **预期结果**：
  - 记录从页面中消失
  - 数据库 `ss_task_log` 对应记录被逻辑删除
  - 返回首页后，时间轴对应记录消失

## 5. 异常与边界测试
### 5.1 未绑定儿童
- **场景**：用户未绑定任何儿童 ID 时进入首页
- **预期结果**：系统应弹出“未绑定儿童”提示，并优雅跳转至配置页或显示空状态

### 5.2 奖励库存与消耗
- **步骤**：模拟孩子端发起兑换，家长端查看“待处理请求”
- **预期结果**：请求显示正确，批准后孩子星星数额按 `star_cost` 正确扣减

## 6. 儿童端核心交互
### 6.1 任务发现与启动
- **步骤**：登录儿童端首页 -> 点击“今日任务”列表中的任务
- **预期结果**：
  - 进入任务详情页
  - 点击“开始执行”，WS2812B 灯环进入蓝色呼吸模式（模拟光语）
  - 屏幕显示环形进度条或倒计时

### 6.2 任务拆解与反馈
- **步骤**：点击任务中的“下一步”
- **预期结果**：
  - 屏幕振动或发出短促音效
  - 进度条更新
  - 最后一个步骤完成后显示“提交凭证”界面

### 6.3 拍照/凭证提交
- **步骤**：点击“拍照提交”并确认
- **预期结果**：
  - 界面显示“正在飞向家长...”动画
  - 任务状态变为“待审核”

### 6.4 奖励兑换申请
- **步骤**：进入“奖励商店” -> 选择一个星星足够的奖励 -> 点击“兑换”
- **预期结果**：
  - 弹出“确认兑换”提示
  - 提交后按钮变为“审核中”或“已申请”
  - 星星余额被锁定（或暂时不扣减直至家长通过）

### 6.5 积分不足提示
- **步骤**：选择一个星星数超过余额的奖励
- **预期结果**：
  - 兑换按钮置灰或弹出“再收集 X 颗星星就能兑换啦”的鼓励文案

## 7. 异常场景 (儿童端)
### 7.1 断网离线模式
- **步骤**：关闭网络环境下完成任务
- **预期结果**：任务进度本地缓存，网络恢复后自动同步至家长端
### 7.2 任务中断处理
- **步骤**：执行任务过程中点击“返回”或“放弃”
- **预期结果**：提示“真的要休息一下吗？进度会保留哦”，确保不会因误触丢失进度
