# 📜 架构变迁编年史 (CHRONICLE)

---

## [2026-04-08] - 2.0 工业级架构升级 (ADR-001)

### 背景 (Context)
1.0 方案对 ADHD 执行功能障碍的支持仅停留在概念层面，技术实现缺乏深度细节（如高并发下的实时审批反馈、多级任务拆解的数据结构）。

### 决策 (Decision)
1. **全栈架构升级**: 后端从普通的 Spring Boot 转向基于 Spring Boot 3.5.x 的 RuoYi-Vue-Plus 核心，前端引入 UniApp X + UTS 以获取原生性能。
2. **三位一体功能引擎**: 
   - **Task Crusher**: 引入 AI 驱动的树形任务拆解。
   - **Scaffolding**: 基于 ZPD 理论的自动降级引导。
   - **Mind Echo**: 多模态情绪洞察。
3. **性能基准**: 设定 100ms 级的实时审批反馈目标。

### 影响 (Consequences)
- **正面**: 显著提升了系统的科学干预深度与商业化潜力。
- **挑战**: UTS 原生插件编写对团队开发能力要求提高；AI 响应时延需要通过异步队列优化。
