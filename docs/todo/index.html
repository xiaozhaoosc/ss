每一个小小的进步 都值得被看见

Small Steps (小步) 是一款融合 ADHD 心理学模型 与 现代分布式架构 的支架式行为辅助系统。我们通过 AI 驱动的任务拆解、多感官实时激励与情感洞察，陪伴每一个家庭跨越成长的障碍。

立即体验 2.0 架构 技术白皮书

三位一体的科学干预生态

📱

Small Steps APP

基于 UniApp X + UTS 打造。儿童端拥有流体能量系统与无压管线布局，家长端实现 100ms 级的实时审批反馈，完美适配 ADHD 儿童的即时奖励需求。

💻

Small Steps UI

Vue 3 (Composition API) 驱动的管理大脑。为教育机构提供任务模版银行、多家庭数据看板与动态 CRUD 生成引擎，让大规模干预变得简单高效。

⚙️

Small Steps API

Spring Boot 3.5.x 核心中枢。集成 Sa-Token 权限体系、Redis Stream 异步架构与 AI 路由引擎，提供 Task Crusher (任务粉碎) 与 Mind Echo (情感回响) 核心算力。

Task Crusher

AI 驱动的任务粉碎机

ADHD 儿童难以处理模糊指令。小步系统通过 AI 算法将“收拾房间”等大型任务递归拆解为“捡起废纸”、“摆好椅子”等 3 分钟内可完成的原子动作，从根源消除执行障碍。

🧩
Mind Echo

情感回响与实时洞察

通过多模态分析孩子的语音汇报与操作特征，Mind Echo 模型能敏锐捕捉挫败、抗拒等情绪波动。当系统检测到负面情绪时，会即时建议家长介入并给予正向鼓励，构建温暖的数字支架。

❤️
Scaffolding

支架式辅助降级 (Fading)

基于 ZPD 理论。系统会自动评估孩子的独立完成度，动态调整引导强度。从全屏视频引导到简单的文字提醒，随着孩子能力的提升，数字支架逐步撤回，最终实现真正的独立成长。

🚀
