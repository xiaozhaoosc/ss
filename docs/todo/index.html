每一个小小的进步 都值得被看见

Small Steps 是一款专为 ADHD 儿童及其家庭设计的支架式行为辅助系统。我们通过科学的激励、明确的任务拆解与温暖的互动，帮助孩子建立自信，陪伴家庭共同成长。

三位一体的科学干预生态

📱

Small Steps APP

亲子互动的核心。儿童端采用游戏化任务流，家长端提供快速状态监控与奖励审批。时刻连接物理与数字世界。

💻

Small Steps UI

专业的管理大脑。为教育机构与干预师提供全局数据大盘、任务银行配置与多家庭业务管理，让干预更科学。

⚙️

Small Steps API

强悍的动力引擎。基于 Spring Boot 3 + Java 21 开发，提供多级任务拆解算法、积分银行与极速响应的后端服务。

Scaffolding

支架式任务拆解

我们不仅仅是列出清单。小步系统支持将复杂的任务（如“整理房间”）拆解为微小的、可执行的操作单元，降低孩子的心理门槛，引导他们一步步走向成功。

🧩
Motivation

积分银行与奖励商店

建立即时的正向反馈循环。通过完成任务收集能量积分，在精心配置的奖励商店兑换亲子特权或实物奖品，让内在动力在成就感中持续迸发。

💎
Data Insight

全方位的行为洞察

通过多维度的积分流水与任务曲线，系统为家长和专家提供直观的数据反馈。不再凭感觉判断，而是通过真实的数据看见孩子的每一次进步与转折。

📊

让关注力，化作生长的力量
