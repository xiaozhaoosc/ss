# Small Steps (小步) 家长端 APP 页面设计规格书 v1.0

> **核心目标**: 降低家长的认知焦虑，提供“上帝视角”但不仅是监控，更是支持。
> **导航结构**: 底部导航栏 (Bottom Navigation Bar) - 5 Tabs

## 1. 全局定义 (Global Definitions)
*   **字体**: 系统默认无衬线字体 (iOS: SF Pro / Android: Roboto)。
*   **主色调**: `#6C9BD2` (疗愈蓝)。
*   **交互**:
    *   下拉刷新 (Pull to refresh): 同步最新硬件状态。
    *   Toast 提示: 硬件指令发送成功/失败。

## 2. P0: 初始设置 (Onboarding)
**功能**: 这里的体验决定了硬件是否会被“吃灰”。必须极度丝滑。

### P0-1: 欢迎与登录
*   **背景**: 温暖的插画（大手牵小手）。
*   **文案**: "Small Steps, Big Dreams. 陪孩子走好每一步。"
*   **登录方式**:
    *   主推: 手机号 / 微信一键登录。
    *   **新增**: 邮箱登录 (Email Login) - 方便海外或隐私敏感用户。

### P0-2: 硬件配对 (Device Pairing)
*   **模式选择**:
    *   **完整体验**: "我有 StarBuddy" -> 进入配对流程。
    *   **纯软模式**: "暂时没有设备" -> **跳过** (进入 App 独立模式)。
*   **搜索页 (硬件模式)**:
    *   动画: 手机发出波纹信号，寻找 StarBuddy。
    *   *提示*: "请长按 StarBuddy 背后的配对键，直到蓝灯闪烁。"
*   **发现设备**:
    *   弹出卡片: "发现一只 StarBuddy (ID: 8820)"。
    *   图片: 硬件实物图。
    *   动作: 点击 "连接"。
*   **配网**: 输入家庭 WiFi 密码 (支持 5G/2.4G 双频更佳，若只能 2.4G 需明确提示)。

### P0-3: 孩子档案 (Child Setup)
*   **昵称**: "给它的小主人起个名字吧"。
*   **生日**: 用于推荐适龄习惯。
*   **挑战选择**: (多选)
    *   [ ] 做作业拖拉
    *   [ ] 情绪易失控
    *   [ ] 容易分心
    *   *作用*: AI 根据此标签生成初始的 "推荐任务包"。

## 3. P1: 首页仪表盘 (Dashboard)
**功能**: 一眼看清“孩子现在状态”和“我需要处理的事”。

### 布局结构 (由上至下)
1.  **状态栏 (Status Header)**
    *   左侧: 孩子头像 + 昵称 ("Leo")。
    *   右侧: 硬件在线状态指示灯 (绿点=在线, 灰点=离线) + 电量图标。
    *   中间: **大字当前状态** (例如: "正在专注: 数学作业", "休息中", "离线").
    *   *背景*: 动态渐变色 (专注时为淡绿, 休息时为淡蓝).
2.  **待办/通知卡片 (Action Cards)**
    *   *优先级最高*: **树洞新消息** (如果有)。
        *   显示: "收到一条新的倾诉 (2分钟前)"。
        *   按钮: "去倾听"。
    *   *次级*: 任务进度。
        *   显示: 进度条 "数学作业: 第 2/5 步"。
3.  **时间轴概览 (Mini Timeline)**
    *   显示最近 3 条活动日志 (例如: "14:00 完成了英语阅读", "10:00 第一次专注失败").
4.  **快捷操作 (Quick Actions)**
    *   FAB (悬浮按钮): **+ 新建任务** (点击进入 P2-1).

## 3. P2: 任务管理 (Task Hub)
**功能**: 布置任务、查看历史、AI 辅助拆解。

### 页面布局
*   **Tab 切换**: "今日任务" | "常规习惯" | "历史归档"。
*   **列表项设计**:
    *   左侧: 任务图标 (自动匹配, 如书本、牙刷)。
    *   中间: 任务名称 + 步骤数 ("数学作业 - 5个步骤").
    *   右侧: 状态标签 ("进行中", "已完成", "未开始").
    *   *交互*: 左滑编辑/删除，点击查看详情。

### 子页面: P2-1 新建/编辑任务 (Task Creator)
这是 AI 介入的核心流程。
1.  **输入区**: 
    *   大文本框: "输入你想让孩子做的事..." (支持语音输入).
    *   *示例提示*: "试着说：让 Leo 读 15 分钟哈利波特"
2.  **AI 处理反馈**:
    *   点击 "✨ AI 拆解"。
    *   加载动画: "正在思考如何把大象装进冰箱..."。
3.  **拆解结果预览 (Steps Preview)**:
    *   卡片列表展示生成的步骤:
        1.  走到书架前 (预计 1min)
        2.  拿出《哈利波特》(预计 1min)
        3.  专注阅读 (预计 15min) [计时器图标]
    *   *操作*: 拖拽排序，点击修改文字，删减步骤。
4.  **底部栏**:
    *   "保存为模板" (Checkbox).
    *   主按钮: **"发送给 StarBuddy"** (点击后触发硬件震动+语音).

## 4. P3: 情绪树洞 (Emotion Tree Hole)
**功能**: 异步倾听孩子的心声，避免当面冲突。

### 页面布局
*   **列表**: 按时间倒序排列的录音卡片。
    *   卡片包含: 日期, 时长, **AI 情绪标签** (如: #沮丧 #寻求帮助 #开心).
    *   *隐私保护*: 默认不转写文字，点击展开后通过指纹/FaceID 解锁查看转写(可选设置).

### 子页面: P3-1 详情与回复 (Detail & Reply)
1.  **播放器**: 波形图可视化。
2.  **AI 洞察**:
    *   "情绪强度: 高"。
    *   "关键词: 数学, 难, 不想做"。
3.  **家长回复 (The Bridge)**:
    *   输入框: 输入文字 (转 TTS 语音发送给硬件) 或 直接录音。
    *   **AI 建议回复**: 系统提供 3 个共情回复选项 (例如: "妈妈听到了，这确实很难，抱抱你").
    *   按钮: "发送回复" (硬件会在下次触碰时播放).

## 5. P4: 洞察报表 (Insights)
**功能**: 用数据缓解焦虑，发现长期模式。

*   **专注力趋势图**: 柱状图 (由 Stitch/ECharts 渲染)。显示每日专注总时长。
*   **情绪日历**: 月视图，每天一个颜色圆点代表当天主导情绪。
    *   点击日期查看当日所有记录。
*   **成就回顾**: "Leo 本周获得了 12 颗星星，点亮了 '早起冠军' 徽章！"

## 7. P6: 奖励配置 (Reward Config)
**功能**: 定义星星的购买力。

### 页面布局 (列表与编辑)
*   **当前上架**:
    *   列表显示: 图标 + 名称 + 所需星星数 + 状态 (上架中/已兑换).
    *   *示例*: "周末公园野餐" (30星), "Switch 游戏时间 1h" (50星).
    *   *操作*: 开关切换上架状态。
*   **添加奖励**:
    *   预设库: 系统推荐的 ADHD 友好奖励 (如: "一次大拥抱", "免做家务券").
    *   自定义: 上传照片，设置数值。
*   **兑换审批**:
    *   收到孩子申请时，弹出确认卡片: "同意" / "暂缓".
