# Small Steps (小步) UI/UX 设计体系说明

> 版本：v1.0.0
> 更新日期：2026-02-01
> 设计核心：ADHD 友好、认知卸载、物理优先

## 1. 设计哲学：为神经多样性而设计
本设计方案的核心不仅仅是美学，而是基于功能神经科学的**认知卸载 (Cognitive Offloading)**。
对于 ADHD 儿童，每一个多余的像素都是噪音。我们的目标是打造一个“外挂前额叶”，而非另一个让孩子分心的玩具。

**核心原则：**
1.  **认知极简**：能由灯光表达的，不上屏幕；能用图形表达的，不用文字。
2.  **情感温润**：系统是盟友而非监工。拒绝引起焦虑的视觉元素（如鲜红色的倒计时、刺耳的警报）。
3.  **即时反馈**：利用多巴胺回路，让每一次操作都有“爽感”反馈，建立正向行为强化。

## 2. 视觉策略：去焦虑化的调色板
我们为 RGB565 屏幕专门定制了一套**低饱和度、高明度**的色彩体系。

### 🎨 色彩心理学运用
*   **拒绝纯红 (#FF0000)**：
    *   *依据*：高饱和度红色会激活杏仁核，引发“战斗或逃跑”的应激反应。
    *   *方案*：使用 **软杏橙 (#F7A35C)** 作为警示/超时颜色。它传递的是“请关注我”，而不是“你搞砸了”。
*   **疗愈蓝 (#6C9BD2)**：
    *   *依据*：主色调选用带有灰度的蓝，视觉后退感强，有助于降低心率，维持情绪稳定。
*   **生长绿 (#8CD0A1)**：
    *   *依据*：用于进度和成功的颜色，避开了荧光绿的刺眼，采用偏向自然的薄荷绿，象征“生长”而非“通过”。

## 3. 硬件交互逻辑：物理世界的映射
在 1.8寸非触摸屏 + 4按键的限制下，UI 必须与物理手感高度统一。

*   **HUD 式布局**：
    *   屏幕被视为“抬头显示器 (HUD)”。所有的导航提示（▲ ▼ OK）都严格对应物理按键的物理位置，降低手眼协调的难度。
*   **灯光语言 (Light Language)**：
    *   屏幕只是信息的载体，**灯环 (WS2812B)** 才是情绪的载体。
    *   *专注中*：绿光呼吸（模拟平稳的呼吸节奏，引导生理同步）。
    *   *待机*：蓝光慢脉动（像一个沉睡的伙伴）。
    *   *庆祝*：彩虹闪烁（高强度的视觉奖励，作为 Ah-ha Moment）。

## 4. 关键功能设计思考

### ⏳ 专注模式 (Focus Mode)
*   **痛点**：数字时间（14:59）对 ADHD 儿童是抽象的，无法感知流逝速度（时间盲区）。
*   **设计**：
    *   **实体化时间**：采用**环形消逝进度条**或**像素沙漏**。时间被设计为一种“正在减少的物质”，让流逝感直观可见。
    *   **非侵入式提醒**：倒计时结束前，先通过灯光变化颜色（绿->黄->橙），而非突兀的声音打断。

### 📝 任务清单 (To-Do List)
*   **微任务拆解**：
    *   不展示“写作业”这种宏大目标，而是拆解为“拿出语文书”、“打开第5页”。
    *   UI 上采用**单一大卡片**聚焦当前步骤，隐藏后续任务，避免产生压迫感。

## 5. App 交互策略：双重世界，一个生态
App 通过拆分为两个情感基调截然不同的模式，解决家长与孩子需求的天然冲突。

### 🎭 家长端 (教练视角)
*   **设计基调**: **专业、冷静、掌控**。
*   **交互核心**: 减少焦虑。
    *   *仪表盘*: 不展示繁琐的全部日志，只展示“今日高光”和“情绪异动”。
    *   *任务生成*: 利用 AI 自动将“抽象指令”（如：做作业）转化为“执行步骤”。

### 🎮 儿童端 (英雄视角)
*   **设计基调**: **高能、夸张、奖励**。
*   **交互核心**: 放大成就。
    *   *星星罐*: 每一个任务的完成，都有实体倒下的金币声和视觉反馈。
    *   *NFC 同步*: 通过物理触碰 StarBuddy 进行数据同步，增加仪式感。
