# Small Steps (小步) UI 设计规范系统 v1.0

> **设计哲学**: 认知极简 (Cognitive Ease) & 情感温润 (Emotional Warmth)
> **目标设备**: 1.8英寸 TFT 屏幕 (128x160 px), 非触摸式

## 1. 视觉风格指南 (Visual Style Guide)

### 色彩平衡 (RGB565 优化)
我们采用了 **低饱和度、低对比度** 的调色板，以最大程度减少 ADHD 用户的焦虑感。

| 用途 | 颜色名称 | Hex | RGB | 心理暗示 |
| :--- | :--- | :--- | :--- | :--- |
| **主色** | **疗愈蓝 (Soft Blue)** | `#6C9BD2` | `(108,155,210)` | 平静、信任、稳定 |
| **成功** | **生长绿 (Mint Green)** | `#8CD0A1` | `(140,208,161)` | 成长、正向反馈 |
| **温润** | **暖沙黄 (Warm Sand)** | `#F5D76E` | `(245,215,110)` | 友好、无威胁 |
| **警告** | **软杏橙 (Soft Apricot)** | `#F7A35C` | `(247,163,92)` | 紧急但不惊慌 |
| **中性** | **雾灰 (Fog Grey)** | `#CCCCCC` | `(204,204,204)` | 结构、降噪 |
| **文本** | **炭灰 (Charcoal)** | `#333333` | `(51,51,51)` | 高可读性 |
| **背景** | **珍珠白 (Pearl White)** | `#F5F5F5` | `(245,245,245)` | 纸质般的舒适感 |

### 排版与布局
*   **网格**: 128x160 px 画布。
*   **字体**: 无衬线像素字体 (本地渲染或位图)。
    *   *大号*: 16px (标题, 计时器)
    *   *中号*: 12px (正文, 菜单项)
    *   *小号*: 10px (说明文字)
*   **间距**:
    *   最小内边距: 4px
    *   区块分隔: 8px

## 2. 图标系统 (像素风)
图标应为 16x16 或 24x24 位图。

- **专注 (沙漏)**: `⏱️` 轮廓风格，动态填充。
- **任务 (勾选)**: `✓` 圆角方框。
- **统计 (图表)**: `📊` 简单的柱状图。
- **设置 (齿轮)**: `⚙️` 4齿齿轮。

## 3. 灯光语言 (WS2812B 灯环)
外部灯光反馈是主要的，屏幕是次要的。

*   **专注中**: 生长绿 (`#8CD0A1`) - 常亮/呼吸效果。
*   **等待/待机**: 疗愈蓝 (`#6C9BD2`) - 慢速呼吸 (3秒周期)。
*   **警示/超时**: 软杏橙 (`#F7A35C`) - 慢速闪烁 (1Hz)。
*   **庆祝**: 彩虹循环 - 快速 (3Hz)。

## 4. 交互模式
*   **上/下键 (Up/Down)**: 导航 / 数值调整。
*   **确认键 (OK)**: 确认 / 长按完成任务。
*   **返回键 (Back)**: 返回 / 长按暂停或放弃。
