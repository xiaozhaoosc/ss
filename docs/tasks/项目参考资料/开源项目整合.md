这是一个为您整理的**“小步 (Small Steps)”项目开源资源全集**。

我将之前推荐过的所有项目按**功能模块**进行了分类，并标注了具体的**参考价值**（是直接用代码，还是只参考思路）。

您可以在开发过程中随时查阅此清单。

### 🧠 一、 后端与架构 (The Brain)

| 项目名称 | 核心技术 | 仓库地址 | 💡 “小步”参考点 (抄作业指南) |
| --- | --- | --- | --- |
| **RuoYi-Vue-Plus** | Spring Boot 3 + Vue3 | [Gitee](https://gitee.com/dromara/RuoYi-Vue-Plus) | **【核心底座】**<br>

<br>1. **Sa-Token**: 抄它的多端登录鉴权（小程序/App/Web）。<br>

<br>2. **OSS模块**: 抄它的文件上传代码（对接 MinIO/阿里云）。<br>

<br>3. **System模块**: 直接用它的用户、角色、部门管理表结构。 |
| **LangChain-Chatchat** | Python + FastAPI | [GitHub](https://github.com/chatchat-space/Langchain-Chatchat) | **【AI 服务参考】**<br>

<br>1. 参考 `server/api.py`：如何优雅地封装 LLM 接口。<br>

<br>2. 参考配置管理：如何管理 Prompt 模板和模型参数。 |
| **ThingsBoard** | Java IoT Platform | [GitHub](https://github.com/thingsboard/thingsboard) | **【MQTT 设计规范】**<br>

<br>**不要抄代码（太重）**，只参考它的 **Topic 设计**：<br>

<br>1. 上报数据: `v1/devices/me/telemetry`<br>

<br>2. 接收指令: `v1/devices/me/rpc/request/+` |

<br>用于处理复杂的定时任务和跨平台消息推送（如：每天早上给家长推日报），无需写代码。 |

### 🤖 二、 硬件架构与驱动 (The Body)

| 项目名称 | 核心技术 | 仓库地址 | 💡 “小步”参考点 (抄作业指南) |
| --- | --- | --- | --- |

<br>虽然它是 C++，但请参考它的**系统架构**：<br>

| **ST7735 (MP)** | MicroPython | *(您已上传)* | **【屏幕驱动】**<br>

<br>您上传的 `st7735.py` 已经很好用了，配合 `framebuf` 做 UI 即可。 |

<br>如果您觉得简单的亮灯太单调，可以去它的源码里找 `FX.cpp`，看看“呼吸灯”、“彩虹跑马灯”的数学算法，翻译成 Python。 |
