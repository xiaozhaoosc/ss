# 家长洞察页面 (Insights Page) 功能实施与 UI 还原设计方案

## 1. 目标与范围 (Goal & Scope)
本设计方案旨在将 `smallsteps-app` 微信小程序/APP 端中的“家长洞察”页面（`src/pages/parent/insights/index.vue`）与最新的 UI 设计图进行像素级对齐，并全链路打通其底层的业务数据接口。当前页面包含两个核心业务组件：**能力发展总览**和**月度情绪热力图**。为了百分之百聚焦目标设计，多余的“成就亮点”模块将被隐藏或移除。

## 2. 数据流与接口对齐 (Data Flow & API Alignment)
当前端所定义的数据结构与后端实际返回的字段存在部分脱节。需要进行以下调整：

### 2.1 能力发展总览 (Ability Radar/Bar Chart)
- **后端接口**: `ParentInsightController.getAbilityRadarByChildId(childId)` 返回格式形如：
  `{ "abilities": ["数学", "社交", "专注", "创造", ...], "scores": [65, 42, 85, 30, ...] }`
- **前端适配**:
  - `src/api/child.ts` 保持调用 `/parent/insight/ability/radar/{childId}`。
  - `index.vue` 中解析后端返回的 `{abilities, scores}`，并将其映射为供柱状图渲染的格式：`[{ label: '数学', value: 65 }, ...]`。
  - **默认值**: 当网络失败或接口返回空时，降级使用设计图所示的占位数据以保障页面结构完整。

### 2.2 月度情绪热力图 (Emotion Heatmap)
- **后端接口**: `ChildAIController.emotionTrend(childId, days)` 或 `/parent/insight/emotion/trend/{childId}`。接口返回 `List<ChildAI>` 列表。
- **数据结构**: `ChildAI` 包含核心字段 `createTime` (互动时间) 和 `emotionType` (情绪类型，1/5: 蓝/平静开心, 3: 黄/兴奋, 2/4/默认: 灰/一般)。
- **前端适配**:
  - 拉取近 30 天的情绪数据。
  - 截取 `createTime` 为 `YYYY-MM-DD` 格式。
  - 在日历渲染时，对比日历单元格的日期与情绪数据列表中的记录。如果匹配，依据 `emotionType` 渲染相应的状态圆点。

## 3. UI 像素级还原细节 (Pixel-Perfect UI Enhancements)

### 3.1 总体布局与头部
- **头部结构**: 标题“家长洞察”位于左侧。右侧包含语言切换按钮 (CN) 胶囊样式和圆角头像。保持现有的 Flex 布局，并精准调整 `font-size` 和边距 (`padding`)，背景色调整为 `#f6f7f8` 以凸显内部卡片。
- **区块标题**: 如“每周重点”等标题需粗体显示，右侧添加带小箭头图标的“详情 >”蓝色文本链接。

### 3.2 柱状图组件 (Bar Chart)
- **布局重构**: 移除原生简陋的 `tooltip`，改为高度定制的双层嵌套结构。
- **底层 (Track)**: 使用浅灰色带圆角的柱体 (`#f3f4f6`)，高度固定，代表 100% 进度。
- **上层 (Fill)**: 使用品牌蓝 (`#6b9bd1`) 填充，底部直角或圆角，顶部圆角。动态绑定 `height` 属性。
- **数值标签 (Value Label)**: 百分比（如 `65%`）不再浮动于柱体外，而是以深色胶囊背景 (`#4b5563`) 白字的形式，精确定位在蓝色进度条 (`Fill`) 的内部顶端。
- **状态总览标签**: “能力发展总览”副标题下方，左侧显示大号黑色粗体“总体良好”，紧随其右侧为浅绿底绿字 (`#10b981`) 的趋势标签 `↑+5%`。右上角保留一个圆形的微缩柱状图图标。

### 3.3 日历热力图 (Calendar Heatmap)
- **头部导航**: `[<] 2026年 4月 [>]` 居中显示，使用图标字符或 Icon。
- **星期表头**: “日 一 二 三 四 五 六”，文字色需调整为浅灰（如 `#9ca3af`），居中对齐。
- **日期网格 (Grid)**:
  - 移除所有多余边框。
  - **空日期**: 渲染为空白块以占位对齐星期几。
  - **当天日期 (Today)**: 圆形品牌蓝背景 (`#6b9bd1`)，白色文字，完全还原设计图的圆形高亮视觉。
  - **普通日期**: 灰色或黑色文字。
  - **情绪标记**: 若当天有情绪记录，在日期数字正下方添加对应颜色的小圆点 (`width: 4px; height: 4px`)。
- **图例 (Legend)**: 底部横向居中排列三种颜色的圆点及其对应文字（平静/开心、兴奋、一般）。

### 3.4 “成就亮点”区块处理
- 为了与给定的设计图焦点100%对齐，页面底部的 `<view class="section last-section">` (即成就亮点) 将被**移除或注释掉**。

## 4. 兜底与异常处理 (Fallback & Error Handling)
- 使用 `try-catch` 包裹 API 调用，保证在接口报错时组件不抛出阻塞性异常。
- 保证 Vue 的响应式数据在接口未返回前有可靠的初始化结构。

## 5. 验收标准 (Acceptance Criteria)
1.  **视觉对齐**: 页面在微信开发者工具或手机上渲染出的样式与提供的图片无视觉差异。
2.  **数据挂载**: 控制台不会报出由于数据结构不对齐导致的方法调用错误。
3.  **组件完备**: 日历月份翻页逻辑正确，当前选中月的第一天在星期栏的位置无偏移。
4.  **干净的代码**: 移除无用代码，重命名/优化 CSS 类。
