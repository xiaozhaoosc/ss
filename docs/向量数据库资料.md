## 1. 核心宪章 (Core Manifesto)

### 1.1 第一法则：安全与隐私 (Safety First)
*   **树洞危机干预 (Crisis Protocol)**:
    *   **机制**: 本地正则库 (`src/security/keywords.json`) 实时扫描语音转文字内容。
    *   **触发**: 命中自伤、暴力等高危词汇。
    *   **响应**: 立即阻断 LLM 上传，APP 切换至“家长紧急指引模式”，锁定娱乐功能。
*   **数据主权**:
    *   所有用户数据（日记、画像）实时存储为 Markdown 格式。
    *   **本地优先 (Local First)**: 数据优先存储于用户设备。
    *   **遗忘权**: 家长可一键清除 AI 对孩子的“画像记忆”。

### 1.2 第二法则：家庭系统观 (Family Systems)
*   **统一战线**: 教育建议需同步推送给所有看护人（爸妈爷奶），确保“教育同频”。
*   **家长关怀**: 系统包含“家长低电量模式”，由 AI 接管基础流程，降低对家长的互动要求。

### 1.3 第三法则：褪色机制 (Scaffolding Fading)
*   **核心理念**: 产品的目标是让孩子最终不需要产品。
*   **褪色算法 (Fading Algorithm)**:
    1.  **Level 1 (强提示)**: 语音 + 炫彩光效 + APP弹窗。
    2.  **Level 2 (弱提示)**: 仅柔和光效。
    3.  **Level 3 (延迟提示)**: 仅在超时未响应时介入。
    4.  **Level 4 (内化)**: 移除物理介质（NFC贴纸），举办毕业仪式。

## 2. 产品定义 (Product Definition)

### 2.1 核心痛点
*   **儿童端**: 执行功能障碍 (Executive Dysfunction)。知道要做，但无法“启动”引擎。
*   **家长端**: 情绪耗竭。陷入“吼叫-内疚”循环。

### 2.2 解决方案三支柱
1.  **AI 任务粉碎机 (Task Crusher)**: 将模糊指令（“收拾房间”）拆解为微步骤（“捡起袜子” + “扔掉纸团”）。
2.  **物理锚点 (Physical Anchors)**: 实体玩偶 + NFC 贴纸，将环境线索外化。
3.  **CBT 专家系统**: 基于认知行为疗法的情绪干预。

### 2.3 硬件体系
*   **Hub**: ESP32 小步玩偶 (UI: 1.8寸屏 + WS2812B 灯环 + 震动)。
*   **Anchor**: NFC 贴纸（绿=启动，黄=路径，紫=冷静）。
*   **Logic**: 扫码 -> MQTT -> 云端处理 -> 状态变更。

## 3. 用户画像 (User Personas)

### 3.1 探索者 Leo (The Child)
*   **年龄**: 8-12 岁
*   **特征**: 聪明、冲动、严重的时间盲区 (Time Blindness)、对屏幕痴迷。
*   **内心独白**: "我也想做好，但我控制不住自己。"
*   **需求**: 即时反馈 (Instant Gratification)，不被评判。

### 3.2 守护者 Sarah (The Parent)
*   **状态**: 焦虑、疲惫、可能也有成人的 ADHD 特质。
*   **痛点**: "我不怕累，我只怕我的努力在毁掉孩子。"
*   **需求**: 看到孩子的微小进步，获得育儿效能感。

## 4. 交互逻辑 (Interaction Logic)

### 4.1 任务执行流
1.  **语音输入**: "我要写作业"。
2.  **AI 拆解**: 生成 3 个微步骤（如"拿出语文书", "打开第5页", "握笔"）。
3.  **物理反馈**: 玩偶亮起**专注蓝**。
4.  **执行监控**: 
    *   每完成一步 -> 拍拍玩偶 -> 获得金币音效。
    *   若超时 -> 玩偶呼吸灯变急促 -> AI 语音温柔提醒。

### 4.2 冷静角逻辑
1.  **触发**: 孩子情绪崩溃。
2.  **动作**: 拿着玩偶去扫“紫色贴纸”（冷静角）。
3.  **响应**: 玩偶播放白噪音，灯光转为**呼吸粉**，APP 暂停所有计时任务。

## 5. AI 人设边界 (AI Persona)

*   **拒绝诊断**: 严禁使用“患病”、“多动症患者”等词汇。使用“执行功能波动”、“能量水平”替代。
*   **非评判性**: 不说“你真懒”，说“看来启动引擎遇到了一点阻力”。
*   **鼓励微小**: 即使只完成了一步，也要给予 full credit 的表扬。
