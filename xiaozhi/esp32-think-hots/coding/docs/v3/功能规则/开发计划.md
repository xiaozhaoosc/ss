# smallsteps-s3-v1

## MCP
行为数据沉淀 (Data MCP)
技能：接入 Postgres / Notion MCP。
场景：每次孩子完成任务，小步直接把“任务名、专注时长、情绪反馈”写入数据库。家长可以在网页端看到自动生成的每周行为分析报表。
4. 📚 知识库与教育 (Knowledge MCP)
技能：接入 Wolfram Alpha / Wikipedia。
场景：在做作业时，通过小步进行百科查询。与普通搜索不同，小步会通过 AI 过滤掉容易分散注意力的冗余信息。
5. 💬 家庭消息同步 (Slack/Discord/WeChat MCP)
技能：信息推送。
场景：当孩子遇到困难触发“求助”时，小步通过 MCP 发送消息给爸爸的手机：“Leo 现在似乎卡在第一步了，也许需要一个拥抱？”
