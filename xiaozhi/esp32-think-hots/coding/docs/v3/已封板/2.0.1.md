## 🐛 问题诊断与解决

### 问题 1: 白屏问题 ✅ 已解决

#### 现象
- 设备启动后屏幕全白
- 日志显示 LVGL 初始化成功
- 背光正常点亮

#### 根本原因
构建系统未正确识别 `smallsteps-s3-v1` 板型,使用了默认的显示驱动配置,导致驱动不匹配。

#### 解决方案
1. **添加板型配置**
   - 在 `main/Kconfig.projbuild` 添加 `BOARD_TYPE_SMALLSTEPS_S3_V1` 选项
   - 在 `config.json` 中启用该配置

2. **调整构建逻辑**
   - 修改 `main/CMakeLists.txt`,将板型判断逻辑提前
   - 确保在编译前正确设置板型宏

3. **使用兼容驱动**
   - 使用 `esp_lcd_new_panel_st7789` 驱动(兼容 ST7735)
   - 配置正确的屏幕参数 (128x160, RGB 顺序, 镜像设置)

#### 验证结果
屏幕正常显示 UI 界面,背光和颜色均正常。

### 问题 2: 麦克风无声 ✅ 已解决

#### 现象
- 按键能触发聆听状态
- 语音唤醒"肉肉同学"无反应
- 初步怀疑麦克风硬件异常

#### 诊断过程

**第一步:添加调试日志**

在 `no_audio_codec.cc` 的 `Read` 函数中添加调试代码:
```cpp
static int debug_counter = 0;
if (debug_counter++ % 50 == 0) {
    // 统计 max, min, avg
    ESP_LOGW(TAG, "MIC Debug: samples=%d, max=%d, min=%d, avg=%d", ...);
}
```

**第二步:初次测试结果**

使用 `I2S_STD_SLOT_RIGHT` 配置:
```
W (7860) NoAudioCodec: MIC Debug: samples=512, max=0, min=0, avg=0
E (22150) NoAudioCodec: MIC SILENT! Check hardware connection!
```
**结论**: 麦克风完全无数据,所有采样值为 0。

**第三步:硬件分析**

INMP441 声道选择机制:
| L/R 引脚状态 | 输出声道 | I2S 配置 |
|-------------|---------|---------|
| 接 GND (0V) | RIGHT | `I2S_STD_SLOT_RIGHT` |
| 接 VDD (3.3V) 或悬空 | LEFT | `I2S_STD_SLOT_LEFT` |

**假设**: 当前硬件的 L/R 引脚可能未接地(悬空或接 VDD)。

**第四步:声道切换测试**

修改代码使用 `I2S_STD_SLOT_LEFT`:
```cpp
static NoAudioCodecSimplex audio_codec(
    ...,
    I2S_STD_SLOT_LEFT   // 改为 LEFT 声道测试
);
```

**第五步:验证结果**

```
W (7970) NoAudioCodec: MIC Debug: samples=512, max=308, min=-1788, avg=715
W (11050) NoAudioCodec: MIC Debug: samples=512, max=7928, min=-5520, avg=2777
W (19060) NoAudioCodec: MIC Debug: samples=512, max=12392, min=-13772, avg=5234
W (51070) NoAudioCodec: MIC Debug: samples=512, max=19598, min=-23112, avg=6769
```

**结论**: ✅ 麦克风立即有数据,音频采样正常!

#### 根本原因
**INMP441 的 L/R 引脚为悬空状态**,导致麦克风输出 LEFT 声道数据,但代码配置读取 RIGHT 声道,结果读取到全 0。

#### 解决方案

**当前方案:软件适配** (已实施)

修改 `smallsteps_s3_v1.cc` 使用 LEFT 声道:
```cpp
static NoAudioCodecSimplex audio_codec(
    AUDIO_INPUT_SAMPLE_RATE, AUDIO_OUTPUT_SAMPLE_RATE,
    AUDIO_I2S_SPK_GPIO_BCLK, AUDIO_I2S_SPK_GPIO_LRCK, AUDIO_I2S_SPK_GPIO_DOUT, 
    I2S_STD_SLOT_LEFT,  // 扬声器使用 LEFT 声道
    AUDIO_I2S_MIC_GPIO_SCK, AUDIO_I2S_MIC_GPIO_WS, AUDIO_I2S_MIC_GPIO_DIN,
    I2S_STD_SLOT_LEFT   // ✅ 硬件 L/R 已接 VDD,使用标准的 LEFT 声道
);
```

**可选方案:硬件修复**

将 INMP441 的 L/R 引脚焊接到 GND,然后修改代码为 `I2S_STD_SLOT_RIGHT`。

#### 验证结果
麦克风正常采集音频数据,幅度范围 300-20000,平均值 600-7000,符合预期。

### 问题 3: 语音唤醒失败 ✅ 已解决

#### 现象
- 麦克风能采集音频数据
- 按键能触发聆听状态
- 说"肉肉同学"无法触发唤醒

#### 诊断过程

**观察日志**:
```
I (6790) CustomWakeWord: Command: rou rou tong xue
Build fst from commands.
1 active speech commands:
Command 1: rou rou tong xue
```
语音唤醒模块已加载,但无法识别语音输入。

**分析可能原因**:
1. 唤醒阈值太高 (当前为 20)
2. 调试日志影响实时性能
3. 音频质量不足

#### 解决方案

**优化 1: 降低唤醒阈值**

修改 `config.json`:
```json
"CONFIG_CUSTOM_WAKE_WORD_THRESHOLD=10"  // 从 20 降到 10
```

**优化 2: 移除调试日志**

删除 `no_audio_codec.cc` 中的调试代码,恢复原始实现:
```cpp
int NoAudioCodec::Read(int16_t* dest, int samples) {
    // ... 原始代码,无调试日志 ...
    return samples;
}
```

#### 验证结果
✅ 语音唤醒"肉肉同学"成功触发,设备进入聆听状态。

## 🔧 技术细节

### 硬件配置

#### 主控芯片
- **MCU**: ESP32-S3-WROOM-1-N16R8
- **Flash**: 16MB
- **PSRAM**: 8MB (Octal)

#### 音频系统

**麦克风 (INMP441)**
- **接口**: I2S (Simplex RX)
- **引脚配置**:
  - SCK: GPIO 41
  - WS: GPIO 42
  - SD: GPIO 2
  - **L/R: VDD** (输出 LEFT 声道)

> [!NOTE]
> **硬件状态**: 经核实,当前硬件的 INMP441 L/R 引脚已可靠接入 VDD,软件已同步配置为 `I2S_STD_SLOT_LEFT`。

**扬声器 (MAX98357A)**
- **接口**: I2S (Simplex TX)
- **引脚配置**:
  - BCLK: GPIO 8
  - LRC: GPIO 21
  - DIN: GPIO 16

#### 显示屏
- **型号**: ST7735 (128x160)
- **接口**: SPI (FSPI)
- **驱动**: esp_lcd_new_panel_st7789 (兼容模式)

#### 按键
- **BOOT**: GPIO 0
- **UP**: GPIO 4
- **DOWN**: GPIO 5
- **OK**: GPIO 6
- **BACK**: GPIO 7

#### 其他外设
- **RGB 灯环 (WS2812B)**: GPIO 15
- **震动马达**: GPIO 1

### 软件配置

#### 唤醒词配置
- **唤醒词**: "肉肉同学" (rou rou tong xue)
- **识别模型**: Multinet7 中文通用识别
- **灵敏度**: 10 (优化后,原为 20)

#### 编译配置
```json
{
    "target": "esp32s3",
    "builds": [{
        "name": "smallsteps-s3-v1",
        "sdkconfig_append": [
            "CONFIG_ESPTOOLPY_FLASHSIZE_16MB=y",
            "CONFIG_PARTITION_TABLE_CUSTOM_FILENAME=\"partitions/v2/16m.csv\"",
            "CONFIG_BOARD_TYPE_SMALLSTEPS_S3_V1=y",
            "CONFIG_LCD_ST7735_128X160=y",
            "CONFIG_USE_CUSTOM_WAKE_WORD=y",
            "CONFIG_SR_MN_CN_MULTINET7_QUANT=y",
            "CONFIG_CUSTOM_WAKE_WORD=\"rou rou tong xue\"",
            "CONFIG_CUSTOM_WAKE_WORD_DISPLAY=\"\\u8089\\u8089\\u540c\\u5b66\"",
            "CONFIG_CUSTOM_WAKE_WORD_THRESHOLD=10"
        ]
    }]
}
```
