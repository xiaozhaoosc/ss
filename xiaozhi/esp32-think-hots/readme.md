# Think-Shots (碎碎念收集器)

> "一句话可随时随地记录，小巧便携，可独立工作。"

## 1. 核心愿景
专为创意工作者、ADHD 人士设计的**低摩擦**想法捕捉终端。它不是为了管理你的生活，而是为了**释放**你的大脑负担。在灵感闪现的 2 秒内，你只需要“按住并说出来”。

## 2. 核心场景
- **随时随地记录**：通过物理按键盲操录音。
- **独立工作**：内置录音、存储与 Wi-Fi 自动同步，不依赖手机开启。
- **蓝牙耳机友好**：支持连接蓝牙耳机进行语音播报反馈（如记录成功提醒）。

## 3. 硬件方案 (ESP32-S3)
- **主控**：ESP32-S3 (双核，支持蓝牙/Wi-Fi 与音频处理并行)。
- **输入**：高灵敏度 I2S MEMS 麦克风 (如 INMP441) + 实体物理按键。
- **反馈**：
  - **视觉**：WS2812B 灯环（紫色=录音，蓝色=同步）。
  - **触觉**：微型震动马达（确认操作）。
  - **听觉**：扬声器或蓝牙耳机播报提示音。

## 4. 软件与 AI 链路
1. **设备端**：VAD (语音活动检测) + I2S 音频采集 -> PSRAM 缓冲 -> 异步 Wi-Fi 上传。
2. **云端**：
   - **ASR**：Whisper 接口转文本。
   - **LLM**：自动摘要、分类、提取关键词/TODO。
3. **客户端**：微信小程序/App 查看整理。

## 5. 优势
- **极简极速**：一键录音，无需解锁手机。
- **离线可用**：Flash 暂存，联网自动同步。
- **零认知负荷**：无需看屏幕，真正的“背景级交互”。
