# PRD: 小步 - Think-Shots (碎碎念收集器)

## 1. 核心故事
"记录应当如同呼吸。当你想到一个点子，按住它，说出来，然后松手。剩下的交给 AI。"

## 2. 交互逻辑 (基于 4 按键 + 1.8寸屏)

### A. 极速记录 (双重触发)
- **物理触发**：长按 OK 键开始录音。
- **语音触发 (Hands-free)**：说出唤醒词 **“肉肉，肉肉”**。
  - **反馈**：耳机中传回轻微的“咚”声（提示音），灯环开始紫色呼吸。
  - **收音**：优先通过蓝牙耳麦 (HFP) 采集语音；若未连接，则通过本地 MEMS 麦克风。
- **自动结束**：静默 1-2 秒后自动停止录音并进入同步。

### B. 离线模式
- 设备未连接 Wi-Fi 时，想法保存在 Flash 缓存中。
- 主页显示：`[!] 3 条未同步`。
- 连接网络后自动后台静默同步。

### C. 预览与重录 (Up/Down 导航)
- **Down 键**：查看最近一次记录。
- **Up 键**：查看想法列表。
- **Back 键**：取消当前操作或返回。

## 3. 设计哲学
- **抗挫折设计**：如果录音失败（如断网），设备震动提醒并保存本地，绝不丢失数据。
- **零查看操作**：硬件必须支持盲操，用户可以在兜里完成“按住-说话-松手”的全过程。

## 4. 规格要求
- **芯片**：ESP32-S3 (Dual Core for Bluetooth & Recording parallel).
- **麦克风**：INMP441 或同类 I2S 硅麦。
- **按键**：带触感的物理按键。
- **尺寸**：约打火机大小 (50x30x12mm)。
