# 常见问题

## 环境配置

### Q: 启动服务时出现数据库连接失败怎么办？

**A:** 请检查以下几点：
1. PostgreSQL 服务是否正常运行
2. 数据库连接配置是否正确（用户名、密码、数据库名）
3. 数据库是否已创建并执行了初始化脚本
4. 防火墙是否允许数据库连接

### Q: 依赖包下载失败怎么办？

**A:** 可以尝试以下方法：
1. 检查网络连接
2. 配置 Maven 镜像源，在 `settings.xml` 文件中添加国内镜像
3. 清理 Maven 本地仓库，删除 `~/.m2/repository` 目录后重新构建

## 开发问题

### Q: 如何添加新的业务模块？

**A:** 按照以下步骤：
1. 在 `smallsteps-modules` 目录下创建新的模块目录
2. 配置 `pom.xml` 文件，添加必要的依赖
3. 按照现有的模块结构创建目录和文件
4. 在 `smallsteps-admin` 的 `pom.xml` 中添加新模块的依赖
5. 启动服务验证模块是否正常加载

### Q: 如何使用 AI 功能？

**A:** 参考 `smallsteps-common/smallsteps-ai` 模块中的示例代码，主要步骤：
1. 配置 AI 服务的 API 密钥
2. 使用 `AIService` 接口调用相应的方法
3. 处理返回的结果并集成到业务逻辑中

## 部署问题

### Q: Docker 部署时出现端口冲突怎么办？

**A:** 修改 `docker-compose.yml` 文件中的端口映射，将冲突的端口改为其他可用端口。

### Q: 生产环境中如何配置 HTTPS？

**A:** 可以通过以下方式：
1. 使用 Nginx 作为反向代理，配置 SSL 证书
2. 在 Spring Boot 中直接配置 HTTPS（不推荐，建议使用反向代理）

## 其他问题

### Q: 如何查看系统日志？

**A:** 日志文件位于 `logs` 目录，可使用以下命令查看：

```bash
tail -f logs/smallsteps.log
```

### Q: 如何监控系统状态？

**A:** 访问 `smallsteps-monitor-admin` 模块提供的监控页面，或者使用 Prometheus + Grafana 进行监控。

### Q: 如何进行性能优化？

**A:** 可以从以下几个方面入手：
1. 数据库索引优化
2. 缓存使用（Redis）
3. 代码优化（减少重复计算、使用异步处理）
4. JVM 调优
5. 数据库连接池配置优化
