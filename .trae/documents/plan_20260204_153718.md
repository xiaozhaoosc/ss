## 任务分析
用户需要：
1. 修改 `docs/dockers/docker-compose.yml` 文件，为 API 和 UI 服务指定版本为 0.0.1
2. 在 `docs/dockers` 目录下增加 readme.md 文件
3. 修改完成后运行 docker compose 执行并测试验证

## 解决方案

### 1. 修改 docker-compose.yml 文件
- 为 `gateway` 服务（UI）添加 `tags` 字段，指定镜像标签为 `small-steps-ui:0.0.1`
- 为 `backend-core` 服务（API）添加 `tags` 字段，指定镜像标签为 `small-steps-api:0.0.1`

### 2. 创建 readme.md 文件
在 `docs/dockers` 目录下创建 readme.md 文件，包含：
- 服务说明
- 版本信息
- 启动指南
- 测试验证方法

### 3. 运行测试验证
- 执行 `docker-compose build` 构建镜像
- 执行 `docker-compose up -d` 启动服务
- 测试服务是否正常运行

## 具体修改

1. **修改 gateway 服务**：
```yaml
gateway:
  <<: *common-opts
  build:
    context: ../../projects/smallsteps-ui
    dockerfile: Dockerfile
    tags:
      - small-steps-ui:0.0.1
  # 其他配置...
```

2. **修改 backend-core 服务**：
```yaml
backend-core:
  <<: *common-opts
  build:
    context: ../../projects/smallsteps-api
    dockerfile: smallsteps-admin/Dockerfile
    tags:
      - small-steps-api:0.0.1
  # 其他配置...
```

3. **创建 readme.md 文件**：详细说明服务配置、版本信息和启动方法

4. **运行测试**：执行 docker compose 命令构建和启动服务，验证服务状态
