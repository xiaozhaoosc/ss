## 技能目录结构调整计划

### 问题分析
当前技能文件被克隆到了 `docs/skills/skills/` 目录（嵌套了两层 skills 目录），而 Trae IDE 可能期望技能文件直接放在 `docs/skills/` 目录下，导致技能显示为空。

### 解决方案

1. **移动技能文件**：将 `docs/skills/skills/` 目录中的内容移动到 `docs/skills/` 目录下
2. **清理多余目录**：删除空的 `docs/skills/skills/` 目录
3. **验证目录结构**：确保技能文件直接位于 `docs/skills/` 目录下
4. **刷新 Trae IDE**：检查技能是否正确显示

### 具体步骤
1. 复制 `docs/skills/skills/` 目录中的所有内容到 `docs/skills/` 目录
2. 删除 `docs/skills/skills/` 目录
3. 验证 `docs/skills/` 目录结构
4. 刷新 Trae IDE 查看技能是否显示
