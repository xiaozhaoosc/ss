## 二、测试用例失败分析

### 2.1 Tab 1: 首页 Dashboard（5/5 失败）

**症状**: 全部 5 个测试在前一轮单独运行时全部通过，全量运行时全部失败。

**根因**: 部署后全量测试期间，API 可能正在重启，导致登录后页面加载异常。测试超时设置偏紧（45秒），登录+页面加载需要约 20 秒。

**修复建议**:
- 增加 `waitForLoadState('domcontentloaded')` 等待
- 在 `loginAsParent` 后增加页面内容验证
- 超时从 45s 增加到 60s

### 2.2 Tab 2: 任务创建器（5/7 失败）

**失败测试**: 2.3 AI 拆解按钮、2.4 孩子选择、2.5 步骤列表、2.6 重复选项、2.7 发布按钮

**根因**: 测试用 `text=/AI 拆解/` 等选择器，但页面使用 Material Icons 字体渲染图标文字（如 `spark`、`library_books`），选择器无法匹配。

**修复建议**:
- 2.3: `AI 拆解` → 使用 `page.locator('text=/AI.*拆解|spark/')` 
- 2.4: `指派给` → 使用 `page.locator('text=/指派|选择孩子/')`
- 2.5: `任务步骤` → 使用 `page.locator('text=/步骤|step/')`
- 2.6: `每天重复` → 使用 `page.locator('text=/重复|repeat/')`
- 2.7: `发布` → 使用 `page.locator('text=/发布|publish/')`

### 2.3 Tab 2: 奖励管理（2/5 失败）

**失败测试**: 3.1 奖励设置页面加载、3.3 添加新奖励按钮、3.4 待处理请求区域

**根因**: 
- 3.1: 奖励页面通过 URL 直接导航，但 `waitForLoadState` 超时
- 3.3: "添加新奖励"按钮选择器 `text=/添加新奖励/` 实际文字是 `add_circle 添加新奖励`
- 3.4: "待处理请求"选择器匹配到了但页面可能未完全加载

### 2.4 Tab 3: 家长洞察（1/6 失败）

**失败测试**: 4.1-4.4, 4.6

**根因**: 洞察页面 Tab 切换后，页面使用 `text=/家长洞察/` 等选择器，但页面标题实际是 `家长洞察` + `CN`（语言切换按钮），选择器可能匹配到错误元素。此外，部分能力维度（专注力 0%）数据为零，导致验证失败。

**数据修复**: 已补充成就数据，但洞察页面的"能力发展总览"数据来自 AI 分析或统计计算，非直接数据库字段。

### 2.5 Tab 4: 个人中心（2/7 失败）

**失败测试**: 5.2 用户名显示、5.7 版本号显示

**根因**:
- 5.2: `text=/ken2zhao/` 选择器可能匹配到多个元素或页面未完全加载
- 5.7: `text=/v\d+\.\d+\.\d+/` 正则匹配版本号，但页面文字是 `版本号 v2.4.0 (Small Steps)`，正则可能需要调整

### 2.6 子页面: 情绪预警（1/2 失败）

**失败测试**: 14.1 情绪预警页面加载

**根因**: 通过 URL 直接导航到情绪预警页面，但页面加载超时或选择器 `text=/情绪|预警|提醒/` 匹配到了页面中非预期的元素。

### 2.7 子页面: 家庭管理（1/1 失败）

**失败测试**: 15.1 绑定孩子页面

**根因**: 导航到 `/pages/parent/family/bind` 后，页面可能重定向或需要额外参数。选择器 `text=/绑定|孩子|添加/` 可能匹配到首页的"添加"按钮而非绑定页面内容。

## 三、修复优先级

| 优先级 | 问题 | 影响范围 | 修复方式 |
|--------|------|----------|----------|
| P0 | Tab 切换坐标不稳定 | 所有 Tab 测试 | 用 `page.locator('[class*="tabbar"] >> text=xxx')` 替代坐标 |
| P0 | 登录后等待不足 | Dashboard 全部 | 增加 `waitForSelector('text=/欢迎回来/')` |
| P1 | 图标文字选择器 | Task Creator | 用 class+text 组合选择器 |
| P1 | 版本号正则 | Profile 5.7 | 改为 `text=/v\d+/` |
| P2 | 情绪预警超时 | Emotion Alert | 增加页面加载等待 |
| P2 | 家庭管理重定向 | Family | 检查页面是否需要参数 |
