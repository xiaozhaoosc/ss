Small Steps - ESP32 客户端

本目录包含 Small Steps 项目的 ESP32-S3 嵌入式客户端代码。该客户端实现了一个基于物理按键和 ST7735 显示屏的专注力辅助工具原型。

🛠 硬件需求

  • 开发板: ESP32-S3
  • 显示屏: 1.8寸 ST7735 TFT LCD (128x160)
  • 输入: 4个微动按键 (上、下、确定、返回)
  • 其他: 杜邦线若干

🔌 硬件接线指南

注意: 本项目代码针对 ESP32-S3 优化，使用硬件 SPI2。

3. 物理按键 (低电平触发)

所有按键均配置为 内部上拉 (PULL_UP)，因此按键的一端接 GPIO，另一端接 GND。

功能 ESP32-S3 GPIO 操作
UP 4 向上选择
DOWN 5 向下选择
OK 6 确认/进入
BACK 7 返回

🚀 快速开始

  1. 刷入固件: 为 ESP32-S3 刷入最新的 MicroPython 固件。
  2. 上传文件: 将以下文件上传到开发板根目录：
    • boot.py
    • main.py
    • st7735.py
  3. 运行: 重启开发板，系统将自动运行 main.py。

🖥️ 功能特性 {#️-功能特性 }

  • 双缓冲渲染: 使用 framebuf 进行全屏双缓冲绘制，画面无闪烁。
  • 基础菜单: 支持 “Focus Mode”, “To-Do List”, “Statistics”, “Settings” 导航。
  • 交互反馈: 按键操作具有简单的视觉反馈（选中项变色、按下确认显示加载条）。

⚠️ 常见问题 {#️-常见问题 }

  1. 屏幕花屏/颜色不对:
    • 检查 st7735.py 中的 MADCTL 寄存器设置 (RGB vs BGR)。
    • 调整 main.py 中的 spi 初始化频率 (默认 20MHz)。
  2. 按键无反应:
    • 确认按键的公共端确实接到了 GND。
    • 目前代码使用阻塞式消抖 (time.sleep)，快速连按可能会被忽略，这是正常现象。
