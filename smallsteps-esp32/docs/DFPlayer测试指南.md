## 🔌 硬件接线

| DFPlayer 引脚 | 连接目标 | 说明 |
|--------------|---------|------|
| **VCC** | 5V 电源板 | 必须 5V |
| **GND** | GND | 共地 |
| **TX** | ESP32 GPIO 18 | DFPlayer → ESP32 |
| **RX** | ESP32 GPIO 17 | ESP32 → DFPlayer |
| **SPK_1** | 扬声器 + | 音频输出 |
| **SPK_2** | 扬声器 - | 音频输出 |

> **注意：** DFPlayer 的 RX 引脚接受 3.3V 逻辑，ESP32 输出正好是 3.3V，无需电平转换。

---

## 💾 SD 卡准备

### 1. 格式化 SD 卡
- **文件系统**：FAT32（必须）
- **容量**：≤32GB

### 2. 创建文件夹和音频文件
```
SD 卡根目录/
└── 01/              ← 文件夹编号（01-99）
    ├── 001.mp3      ← 文件编号（001-255）
    ├── 002.mp3
    └── 003.mp3
```

### 3. 音频文件要求
- **格式**：MP3 或 WAV
- **码率**：推荐 128kbps（避免高码率）
- **命名**：必须是 3 位数字（001.mp3, 002.mp3...）

### 4. 插入 SD 卡
将准备好的 SD 卡插入 DFPlayer 模块的卡槽。

## 🔧 故障排查

### 问题 1：没有声音
**可能原因：**
- SD 卡未格式化为 FAT32
- 音频文件命名不正确（必须是 001.mp3, 002.mp3）
- 文件不在 `/01/` 文件夹中
- 扬声器未连接或损坏
- 5V 电源未连接

**解决方法：**
1. 重新格式化 SD 卡为 FAT32
2. 检查文件命名和文件夹结构
3. 用万用表测量 DFPlayer VCC 引脚是否有 5V
4. 更换扬声器测试

---

### 问题 2：声音断断续续或有杂音
**可能原因：**
- SD 卡质量差或读取速度慢
- 音频文件码率过高
- 电源不稳定

**解决方法：**
1. 更换高质量 SD 卡（Class 10 或更高）
2. 重新编码音频文件为 128kbps MP3
3. 检查 5V 电源板输出是否稳定

---

### 问题 3：串口报错或无响应
**可能原因：**
- UART 引脚接线错误（TX/RX 接反）
- 波特率不匹配
- DFPlayer 模块损坏

**解决方法：**
1. 检查接线：ESP32 TX (GPIO 17) → DFPlayer RX
2. 检查接线：ESP32 RX (GPIO 18) → DFPlayer TX
3. 尝试重置 DFPlayer（断电重启）
