# 震动马达电平转换解决方案

## 问题描述

**硬件配置：**
- ESP32-S3 开发板（3.3V 逻辑）
- 电子积木震动马达模块（5V 逻辑，MOS 管高电平触发）
- 5V 电源板（已正常输出 5V）

**问题现象：**
- 代码运行正常，无报错
- 5V 电源供电正常
- 接线牢固
- **马达不震动**

**根本原因：**
ESP32 GPIO 输出的 3.3V 逻辑电平不足以完全触发马达模块的 MOS 管（需要 ≥4V）。

## 推荐方案：NPN 三极管驱动电路

### 所需材料
- 1 个 NPN 三极管（S8050 或 2N2222 或 2N3904）
- 1 个 1kΩ 电阻（色环：棕黑红金）
- 杜邦线若干

### 工作原理
```
ESP32 GPIO 6 (3.3V) → 三极管基极 → 三极管导通
三极管导通 → 集电极接地 → 马达 IN 被拉低
马达 IN 被拉低 → MOS 管导通 → 马达震动
```

**注意：** 这个电路是**反向逻辑**：
- ESP32 输出 HIGH → 三极管导通 → 马达 IN = LOW → 马达**不震动**
- ESP32 输出 LOW → 三极管截止 → 马达 IN = HIGH (5V 上拉) → 马达**震动**

### 接线图

```
                    ┌─────────────┐
                    │  5V 电源板  │
                    └──┬──────┬───┘
                       │      │
                      5V     GND
                       │      │
         ┌─────────────┼──────┼─────────────┐
         │             │      │             │
         │    ┌────────┴──────┴────────┐    │
         │    │   震动马达模块          │    │
         │    │  ┌───┐                 │    │
         │    │  │ M │  VCC ─────────┐ │    │
         │    │  │ O │  GND ─────────┼─┼────┼─── GND (共地)
         │    │  │ T │  IN  ─────────┼─┼────┘
         │    │  │ O │               │ │
         │    │  │ R │               │ │
         │    │  └───┘               │ │
         │    └─────────────────────┬─┘ │
         │                          │   │
         │                          │   │
         │                    ┌─────┴───┴─────┐
         │                    │  NPN 三极管    │
         │                    │   (S8050)      │
         │                    │                │
         │                    │   C (集电极)   │◄─── 连接马达 IN
         │                    │   B (基极)     │◄─── [1kΩ] ◄─── ESP32 GPIO 6
         │                    │   E (发射极)   │◄─── GND
         │                    └────────────────┘
         │
         └─── ESP32-S3 ───────────────────────────┘
```

### 详细接线步骤

1. **三极管引脚识别**（S8050 正面朝自己，引脚向下）：
   ```
   左 → 发射极 (E)
   中 → 基极 (B)
   右 → 集电极 (C)
   ```

2. **连接顺序**：
   ```
   ESP32 GPIO 6 ──[1kΩ 电阻]── 三极管 B (基极)
   三极管 C (集电极) ── 马达 IN
   三极管 E (发射极) ── GND (共地)
   
   马达 VCC ── 5V 电源板输出
   马达 GND ── GND (共地)
   ```

3. **验证接线**：
   - 用万用表测量三极管 E 到 GND：应为 0Ω（短路）
   - 测量三极管 B 到 GPIO 6：应为 1kΩ
   - 测量马达 VCC 到 5V：应为 5V

## 软件适配

### 原代码（GPIO 高电平触发）
```python
motor = Pin(6, Pin.OUT)
motor.value(1)  # 震动
motor.value(0)  # 停止
```

### 三极管方案代码（反向逻辑）
```python
motor = Pin(6, Pin.OUT)
motor.value(0)  # 震动（三极管截止，IN 被上拉到 5V）
motor.value(1)  # 停止（三极管导通，IN 被拉到 GND）
```

**或者封装为正向逻辑：**
```python
class HapticMotor:
    def __init__(self, pin_num):
        self.motor = Pin(pin_num, Pin.OUT)
        self.motor.value(1)  # 初始化为停止状态
    
    def vibrate(self):
        """开始震动"""
        self.motor.value(0)  # 反向逻辑
    
    def stop(self):
        """停止震动"""
        self.motor.value(1)  # 反向逻辑

# 使用示例
motor = HapticMotor(6)
motor.vibrate()  # 震动
time.sleep(1)
motor.stop()     # 停止
```

## 验证测试

使用以下脚本验证三极管电路：

```python
from machine import Pin
import time

# 反向逻辑测试
motor = Pin(6, Pin.OUT)

print("测试开始（反向逻辑）")
print("设置 GPIO 6 = LOW，马达应该震动...")
motor.value(0)  # 三极管截止，IN 上拉到 5V
time.sleep(3)

print("设置 GPIO 6 = HIGH，马达应该停止...")
motor.value(1)  # 三极管导通，IN 拉到 GND
time.sleep(1)

print("测试完成")
```

## 常见问题

### Q1：为什么是反向逻辑？
**A：** 因为 NPN 三极管导通时会将集电极拉到地（GND），而马达模块的 MOS 管是"高电平触发"，所以当 IN 被拉低时，MOS 管截止，马达不震动。

### Q2：可以用 PNP 三极管吗？
**A：** 可以，但接线更复杂。PNP 需要将发射极接 5V，集电极接马达 IN，基极通过电阻接 GPIO。

### Q3：1kΩ 电阻可以用其他阻值吗？
**A：** 可以，范围 470Ω ~ 10kΩ 都可以。阻值越小，驱动能力越强，但功耗越大。
