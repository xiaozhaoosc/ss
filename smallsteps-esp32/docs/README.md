# Small Steps ESP32 文档

## 项目概述

Small Steps ESP32 是 Small Steps 系统的硬件终端部分，基于 ESP32-S3 开发，为儿童提供物理交互界面和环境线索外化功能。

### 核心功能

- **专注模式**：通过光语和声语帮助儿童保持专注
- **任务提醒**：定时提醒儿童完成任务
- **NFC 互动**：通过 NFC 贴纸触发特定场景
- **情绪反馈**：通过灯光和声音反馈儿童情绪状态
- **离线工作**：支持离线缓存和本地任务执行

## 硬件规格

- **主控芯片**：ESP32-S3
- **显示屏**：1.8寸 ST7735 屏幕 (128x160)
- **按键**：4个物理按键
- **灯光**：WS2812B 灯环
- **通信**：Wi-Fi、BLE、NFC
- **音频**：DFPlayer 硬件解码
- **存储**：microSD 卡
- **电源**：锂电池

## 技术栈

- **编程语言**：MicroPython
- **通信协议**：MQTT / WebSocket
- **文件系统**：FAT32 (SD卡)
- **开发环境**：Thonny / VS Code + PyMakr

## 快速开始

### 环境要求

- ESP32-S3 开发板
- MicroPython 固件
- Thonny IDE 或 VS Code + PyMakr
- microSD 卡
- 必要的硬件组件（显示屏、按键、灯环等）

### 固件烧录

1. **下载 MicroPython 固件**

从 [MicroPython 官网](https://micropython.org/download/esp32s3/) 下载适合 ESP32-S3 的固件。

2. **烧录固件**

使用 esptool 烧录固件：

```bash
esptool.py --chip esp32s3 --port /dev/ttyUSB0 write_flash -z 0x0 esp32s3-20240101-v1.22.0.bin
```

3. **上传文件**

使用 Thonny 或 PyMakr 将项目文件上传到 ESP32-S3。

4. **配置网络**

修改 `config.py` 中的网络配置：

```python
WIFI_SSID = "your_wifi_ssid"
WIFI_PASSWORD = "your_wifi_password"
```

5. **启动设备**

重启 ESP32-S3，设备将自动启动并连接到网络。

## 功能模块

### 专注模式

专注模式通过灯光和声音帮助儿童保持专注：

- **灯光效果**：不同颜色和节奏的灯光
- **声音提示**：定时声音提醒
- **专注时长**：可配置的专注时间

### 任务管理

设备可以接收和执行任务：

- **任务同步**：从服务器同步任务
- **任务执行**：分步执行任务
- **进度跟踪**：记录任务完成情况
- **离线工作**：支持离线执行任务

### NFC 互动

通过 NFC 贴纸触发特定场景：

- **场景切换**：不同 NFC 贴纸对应不同场景
- **任务启动**：通过 NFC 启动特定任务
- **奖励触发**：通过 NFC 给予奖励

### 设备管理

设备管理功能：

- **配置管理**：远程配置设备参数
- **状态监控**：监控设备状态和电池电量
- **固件更新**：支持 OTA 固件更新

## 常见问题

### Q: 设备无法连接 Wi-Fi 怎么办？

**A:** 检查以下几点：
1. Wi-Fi 名称和密码是否正确
2. Wi-Fi 信号是否稳定
3. 设备是否在 Wi-Fi 覆盖范围内
4. 尝试重启设备

### Q: 屏幕不显示怎么办？

**A:** 检查以下几点：
1. 屏幕接线是否正确
2. 屏幕驱动是否正确加载
3. 尝试重新上传 `st7735.py` 文件

### Q: 音频不播放怎么办？

**A:** 检查以下几点：
1. SD 卡是否正确插入
2. 音频文件是否存在于正确位置
3. DFPlayer 是否正确接线
4. 尝试运行 `test_dfplayer.py` 测试音频播放

## 故障排除

### 设备无法启动

1. 检查电源连接
2. 检查固件是否正确烧录
3. 检查 `boot.py` 文件是否存在且无错误

### 无法连接到服务器

1. 检查网络连接
2. 检查 MQTT 服务器配置
3. 检查防火墙设置

### 任务不同步

1. 检查网络连接
2. 检查 MQTT 订阅是否正确
3. 检查服务器是否正常运行
