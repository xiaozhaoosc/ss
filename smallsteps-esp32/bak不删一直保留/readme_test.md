# 硬件调试指南 (Hardware Verification Guide)

> **对应脚本**: `test_hw.py`  
> **目标**: 验证 ESP32-S3、ST7735 屏幕、物理按键是否正确连接并工作。

## 1. 调试前准备 (Pre-flight Check)

在运行代码前，请务必再次检查排线。任何一根线接错都可能导致屏幕不亮或报错。

## 2. 运行测试脚本 (How to Run)

1.  打开 **Thonny IDE**。
2.  连接 ESP32-S3 开发板。
3.  确保 `lib/` 目录下（或根目录）已有 `st7735.py` 驱动文件。
4.  打开 `test_hw.py` 文件。
5.  点击 **运行 (Run)** 按钮 (F5)。

---

## 3. 验证步骤与预期现象 (Verification Cycle)

脚本会自动按顺序执行以下测试：

### Step 1: 屏幕色彩测试
*   **现象**: 屏幕依次全屏显示 **红 -> 绿 -> 蓝 -> 白 -> 黑**。
*   **时长**: 每个颜色停留 0.5 秒。
*   **✅ 通过标准**: 颜色显示正确，无花屏，无噪点。
    *   *❌ 故障*: 颜色反了 (如红变蓝) -> 修改 `st7735.py` 的 `MADCTL` (0xC0 改为 0x00 或 0x08)。
    *   *❌ 故障*: 屏幕边缘有杂色 -> 修改 `st7735.py` 的 `xstart/ystart` 偏移量。

### Step 2: 文字渲染测试
*   **现象**: 屏幕显示黄色标题 "Hardware Test"，下方显示按键引脚说明。
*   **✅ 通过标准**: 文字清晰可读，方向正确（未镜像/倒置）。

### Step 3: 按键交互测试 (Interactive)
*   **现象**: 控制台输出 `Entering Button Loop...`。
*   **操作**: 分别按下板子上的 UP, DOWN, OK, BACK 键。
*   **✅ 通过标准**: 
    1.  按下按键时，Thonny 控制台打印对应的 `Button: UP` 等。
    2.  屏幕上对应的矩形块你会从 **黑色** 变为 **绿色**。
    3.  松手后，矩形块变回黑色。

## 4. 常见故障排除 (Troubleshooting)

### Q1: 运行报错 `OSError: [Errno 19] ENODEV`
*   **原因**: 引脚定义错误或硬件 SPI 初始化失败。
*   **解法**: 检查 `device.py` 中的 `SPI(2, ...)` 参数是否被误改，确认 ESP32-S3 是否刷了正确的固件。

### Q2: 屏幕全白，什么都不显示
*   **原因**: 
    1.  如果 BLK (背光) 亮但没图像 -> 检查 **SDA(11)** 和 **SCK(12)** 是否接反。
    2.  检查 **RES(46)** 是否接好，如果复位失败屏幕无法初始化。

### Q3: 按键一直显示被按下 (一直打印 Button: UP)
*   **原因**: 引脚短路到了 GND，或者微动开关本身坏了（常闭）。
*   **验证**: 拔掉该按键的杜邦线，看是否停止打印。

### Q4: 屏幕颜色很暗
*   **原因**: 3.3V 供电不足。
*   **解法**: 尝试将 VCC 接到 ESP32 的 **5V** 脚（大部分 ST7735 模块自带稳压，支持 5V）。
