# 音效文件说明

## 音效列表

本项目使用 Kenney Interface Sounds 音效包，共 7 个音效文件。

### 文件映射

| 文件名 | 原始文件 | 用途 | 特点 |
|--------|---------|------|------|
| `001.wav` | `bong_001.ogg` | 欢迎音效 | 温和的钟声，友好不刺耳 |
| `002.wav` | `select_003.ogg` | 新任务提示音 | 清脆的选择音，吸引注意力 |
| `003.wav` | `confirmation_002.ogg` | 步骤完成音效 | 积极的确认音，正向反馈 |
| `004.wav` | `maximize_006.ogg` | 任务完成音乐 | 上升的音调，庆祝感强 |
| `005.wav` | `click_001.ogg` | 按键反馈音 | 简短清脆，即时反馈 |
| `006.wav` | `minimize_003.ogg` | 暂停音效 | 下降的音调，表示暂停 |
| `007.wav` | `error_003.ogg` | 错误音效 | 柔和的错误音，不引发焦虑 |

## 音频规格

- **格式**: WAV (PCM)
- **采样率**: 16000 Hz
- **声道**: Mono (单声道)
- **位深**: 16-bit
- **文件大小**: 约 5-20 KB/文件

## 使用方法

### 1. 转换音效文件

```bash
# 运行转换脚本
python convert_sounds.py
```

### 2. 复制到 SD 卡

将生成的 `sounds` 目录复制到 SD 卡根目录：

```
SD卡根目录/
├── sounds/
│   ├── 001.wav
│   ├── 002.wav
│   ├── 003.wav
│   ├── 004.wav
│   ├── 005.wav
│   ├── 006.wav
│   └── 007.wav
```

### 3. 在代码中使用

```python
import config

# 播放音效
device.play_sound(config.SOUND_NEW_TASK)  # 播放新任务提示音
device.play_sound(config.SOUND_STEP_COMPLETE)  # 播放步骤完成音效
```

## 设计理念

### ADHD 友好设计

1. **短促清晰**: 音效时长短，不会分散注意力
2. **音调柔和**: 温和的音效，不会引发焦虑
3. **可区分性强**: 不同类型音效差异明显，易于识别
4. **正向反馈**: 完成音效积极向上，鼓励孩子继续

### 避免的设计

- ❌ 过长的音效（超过 2 秒）
- ❌ 刺耳的高频音
- ❌ 过于兴奋的音效（可能过度刺激）
- ❌ 游戏化的音效（避免联想到游戏而分心）

## 注意事项

1. **SD 卡格式**: 必须使用 FAT32 格式
2. **文件命名**: 严格按照 `001.wav` - `007.wav` 命名
3. **目录结构**: 必须放在 `/sounds/` 目录下
4. **音频格式**: 必须是 16kHz Mono WAV 格式
