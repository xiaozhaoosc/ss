# Small Steps 需求规约

## 1. 简介

### 1.1 文档目的
本文档旨在详细规约 Small Steps 系统的功能需求、非功能需求、数据需求和验收标准，为系统设计、开发和测试提供明确的依据。

### 1.2 术语定义
| 术语 | 解释 |
|------|------|
| ADHD | 注意缺陷多动障碍，一种常见的儿童神经发育障碍 |
| CBT | 认知行为疗法，一种心理治疗方法 |
| AI | 人工智能 |
| MQTT | 消息队列遥测传输协议，用于物联网设备通信 |
| ESP32-S3 | 一种微控制器，用于硬件设备 |
| PRD | 产品需求文档 |
| UI | 用户界面 |
| API | 应用程序编程接口 |

## 2. 功能需求

### 2.1 硬件终端功能

#### 2.1.1 专注模式
- **功能描述**：通过灯光和声语帮助儿童保持专注
- **输入**：用户通过按键进入专注模式，可设置专注时长
- **输出**：灯光变化、声音提示、震动反馈
- **详细需求**：
  - 支持多种专注模式（如深度专注、轻度专注）
  - 可调节灯光颜色和节奏
  - 可调节声音提示频率
  - 专注结束后给予积极反馈

#### 2.1.2 任务提醒
- **功能描述**：定时提醒儿童执行任务
- **输入**：从服务器接收任务信息和提醒时间
- **输出**：灯光提醒、声音提醒、屏幕显示
- **详细需求**：
  - 支持多个任务的提醒
  - 可设置提醒频率和方式
  - 提醒时显示任务名称和步骤
  - 支持 snooze 功能

#### 2.1.3 NFC 互动
- **功能描述**：通过 NFC 贴纸触发特定场景
- **输入**：NFC 贴纸扫描
- **输出**：相应的场景启动、灯光和声音反馈
- **详细需求**：
  - 支持不同 NFC 贴纸对应不同场景
  - 可配置 NFC 贴纸的功能
  - 扫描后给予即时反馈
  - 支持离线 NFC 功能

#### 2.1.4 情绪反馈
- **功能描述**：通过灯光和声音反馈儿童情绪状态
- **输入**：从服务器接收情绪分析结果
- **输出**：灯光颜色变化、声音提示
- **详细需求**：
  - 不同情绪对应不同灯光颜色
  - 提供情绪调节的声音提示
  - 支持情绪表达的交互界面

### 2.2 移动端 App 功能

#### 2.2.1 儿童端功能

##### 2.2.1.1 任务执行
- **功能描述**：儿童按照步骤执行任务
- **输入**：任务步骤选择、完成确认
- **输出**：任务进度显示、完成反馈、积分奖励
- **详细需求**：
  - 清晰显示任务步骤
  - 完成步骤时给予即时反馈
  - 支持任务进度保存
  - 完成任务后自动获得积分

##### 2.2.1.2 奖励系统
- **功能描述**：儿童浏览和兑换奖励
- **输入**：奖励选择、兑换请求
- **输出**：奖励列表、积分余额、兑换结果
- **详细需求**：
  - 显示可用奖励和所需积分
  - 显示当前积分余额
  - 支持奖励兑换请求
  - 显示兑换历史记录

##### 2.2.1.3 情绪表达
- **功能描述**：儿童表达情绪并获得支持
- **输入**：情绪选择、情绪描述
- **输出**：情绪反馈、调节建议
- **详细需求**：
  - 提供简单的情绪选择界面
  - 针对不同情绪提供相应反馈
  - 提供情绪调节的建议
  - 支持与家长分享情绪

#### 2.2.2 家长端功能

##### 2.2.2.1 任务管理
- **功能描述**：家长创建和管理任务
- **输入**：任务名称、描述、奖励、截止时间
- **输出**：任务列表、任务状态、完成情况
- **详细需求**：
  - 支持创建日常任务和一次性任务
  - 支持设置任务奖励积分
  - 支持查看任务执行状态
  - 支持任务模板管理

##### 2.2.2.2 奖励管理
- **功能描述**：家长配置和管理奖励
- **输入**：奖励名称、描述、所需积分、图片
- **输出**：奖励列表、兑换请求、兑换记录
- **详细需求**：
  - 支持添加、编辑、删除奖励
  - 支持设置奖励所需积分
  - 支持批准或拒绝兑换请求
  - 支持查看兑换历史记录

##### 2.2.2.3 数据分析
- **功能描述**：家长查看孩子的行为和情绪数据
- **输入**：数据查询条件
- **输出**：数据报表、趋势分析、育儿建议
- **详细需求**：
  - 提供任务完成率报表
  - 提供专注时间分析
  - 提供情绪变化趋势
  - 提供基于数据的育儿建议

##### 2.2.2.4 设备管理
- **功能描述**：家长管理硬件设备
- **输入**：设备注册、配置参数
- **输出**：设备列表、设备状态、配置结果
- **详细需求**：
  - 支持设备注册和绑定
  - 支持配置设备参数
  - 支持查看设备状态
  - 支持固件更新

### 2.3 管理后台功能

#### 2.3.1 用户管理
- **功能描述**：管理系统用户账号
- **输入**：用户信息、权限设置
- **输出**：用户列表、用户状态
- **详细需求**：
  - 支持添加、编辑、删除用户
  - 支持设置用户权限
  - 支持用户状态管理
  - 支持用户登录日志查看

#### 2.3.2 数据大盘
- **功能描述**：查看系统整体数据
- **输入**：数据查询条件
- **输出**：系统数据概览、趋势分析
- **详细需求**：
  - 显示系统用户数量和活跃度
  - 显示任务完成情况
  - 显示情绪数据分布
  - 显示设备在线状态

#### 2.3.3 Prompt 模板管理
- **功能描述**：管理 AI 提示词模板
- **输入**：模板内容、参数设置
- **输出**：模板列表、测试结果
- **详细需求**：
  - 支持添加、编辑、删除模板
  - 支持模板分类管理
  - 支持模板测试
  - 支持模板版本管理

### 2.4 AI 中台功能

#### 2.4.1 任务拆解
- **功能描述**：将复杂任务拆解为微步骤
- **输入**：任务名称、描述、儿童年龄
- **输出**：拆解后的任务步骤
- **详细需求**：
  - 根据任务类型自动拆解
  - 根据儿童年龄调整步骤难度
  - 确保步骤简单明了
  - 支持自定义拆解规则

#### 2.4.2 情绪分析
- **功能描述**：分析儿童情绪状态
- **输入**：情绪表达、行为数据
- **输出**：情绪类型、强度、建议
- **详细需求**：
  - 识别常见情绪类型
  - 评估情绪强度
  - 提供情绪调节建议
  - 支持情绪趋势分析

#### 2.4.3 智能推荐
- **功能描述**：根据儿童情况推荐任务和奖励
- **输入**：儿童历史数据、偏好
- **输出**：个性化推荐内容
- **详细需求**：
  - 根据完成情况推荐任务
  - 根据兴趣推荐奖励
  - 根据情绪状态推荐活动
  - 支持推荐理由说明

## 3. 非功能需求

### 3.1 性能需求
- **响应时间**：App 操作响应时间 < 1秒
- **设备连接**：设备与服务器连接延迟 < 2秒
- **数据同步**：数据同步时间 < 5秒
- **系统容量**：支持同时在线用户数 > 1000
- **存储容量**：支持存储 10000+ 任务和奖励数据

### 3.2 可靠性需求
- **系统可用性**：系统可用性 > 99.9%
- **数据可靠性**：数据丢失率 < 0.1%
- **设备可靠性**：设备正常运行时间 > 99%
- **故障恢复**：系统故障恢复时间 < 30分钟

### 3.3 安全性需求
- **数据加密**：所有敏感数据加密存储和传输
- **访问控制**：基于角色的访问控制
- **身份认证**：支持多因素认证
- **数据隐私**：符合儿童数据隐私保护法规
- **安全审计**：记录所有重要操作日志

### 3.4 兼容性需求
- **设备兼容性**：支持 iOS 13+ 和 Android 6+ 设备
- **浏览器兼容性**：支持 Chrome、Firefox、Safari、Edge 最新版本
- **网络兼容性**：支持 2G、3G、4G、5G 和 Wi-Fi 网络
- **硬件兼容性**：支持 ESP32-S3 系列设备

### 3.5 可扩展性需求
- **模块扩展性**：支持模块化添加新功能
- **API 扩展性**：支持 API 版本管理和扩展
- **AI 扩展性**：支持 AI 模型的更新和替换
- **硬件扩展性**：支持硬件设备的功能扩展

## 4. 数据需求

### 4.1 数据模型

#### 4.1.1 用户数据
- **家长用户**：用户ID、用户名、密码、昵称、邮箱、手机号、角色
- **儿童用户**：儿童ID、姓名、年龄、性别、家长ID、头像

#### 4.1.2 任务数据
- **任务**：任务ID、任务名称、描述、创建者ID、儿童ID、奖励积分、截止时间、状态
- **任务步骤**：步骤ID、任务ID、步骤名称、描述、顺序、状态

#### 4.1.3 奖励数据
- **奖励**：奖励ID、奖励名称、描述、所需积分、图片
- **积分记录**：记录ID、儿童ID、积分、类型、描述、时间
- **兑换记录**：记录ID、儿童ID、奖励ID、状态、时间

#### 4.1.4 设备数据
- **设备**：设备ID、设备名称、儿童ID、状态、电池电量、最后在线时间
- **设备配置**：配置ID、设备ID、配置项、值

#### 4.1.5 情绪数据
- **情绪记录**：记录ID、儿童ID、情绪类型、强度、时间、描述
- **情绪分析**：分析ID、情绪记录ID、分析结果、建议

#### 4.1.6 系统数据
- **用户角色**：角色ID、角色名称、权限
- **系统配置**：配置项、值
- **操作日志**：日志ID、用户ID、操作类型、操作内容、时间

### 4.2 数据存储
- **数据库**：PostgreSQL
- **缓存**：Redis
- **文件存储**：对象存储服务
- **设备存储**：本地文件系统

### 4.3 数据同步
- **实时同步**：设备与服务器实时数据同步
- **离线同步**：设备离线时数据本地存储，在线后同步
- **数据一致性**：确保多端数据一致性

## 5. 验收标准

### 5.1 功能验收

#### 5.1.1 硬件终端验收
- **专注模式**：能够成功进入专注模式，灯光和声语能够帮助儿童保持专注
- **任务提醒**：能够按时提醒儿童执行任务，提醒方式清晰有效
- **NFC 互动**：能够通过 NFC 贴纸触发相应场景，反馈及时准确
- **情绪反馈**：能够根据情绪状态提供相应的灯光和声音反馈

#### 5.1.2 移动端 App 验收
- **儿童端**：任务执行流程清晰，奖励系统运行正常，情绪表达功能有效
- **家长端**：任务管理功能完善，奖励管理操作便捷，数据分析准确有用，设备管理功能正常

#### 5.1.3 管理后台验收
- **用户管理**：能够成功管理用户账号和权限
- **数据大盘**：能够显示系统整体数据和趋势
- **Prompt 模板管理**：能够管理和测试 AI 提示词模板

#### 5.1.4 AI 中台验收
- **任务拆解**：能够将复杂任务拆解为合理的微步骤
- **情绪分析**：能够准确分析儿童情绪状态并提供建议
- **智能推荐**：能够根据儿童情况提供个性化推荐

### 5.2 非功能验收

#### 5.2.1 性能验收
- **响应时间**：App 操作响应时间 < 1秒
- **设备连接**：设备与服务器连接稳定，延迟 < 2秒
- **数据同步**：数据同步及时准确，时间 < 5秒
- **系统容量**：能够支持 1000+ 同时在线用户

#### 5.2.2 可靠性验收
- **系统可用性**：系统运行稳定，可用性 > 99.9%
- **数据可靠性**：数据存储和传输可靠，丢失率 < 0.1%
- **设备可靠性**：设备运行稳定，正常运行时间 > 99%

#### 5.2.3 安全性验收
- **数据加密**：敏感数据能够正确加密存储和传输
- **访问控制**：能够有效控制用户访问权限
- **身份认证**：能够正确验证用户身份
- **数据隐私**：符合儿童数据隐私保护法规

#### 5.2.4 兼容性验收
- **设备兼容性**：能够在 iOS 13+ 和 Android 6+ 设备上正常运行
- **浏览器兼容性**：能够在主流浏览器上正常运行
- **网络兼容性**：能够在不同网络环境下正常运行
- **硬件兼容性**：能够与 ESP32-S3 系列设备正常配合使用

### 5.3 用户体验验收
- **儿童端**：界面友好，操作简单，反馈及时，游戏化元素丰富
- **家长端**：功能完备，数据清晰，操作高效，界面专业
- **硬件设备**：交互流畅，反馈明确，操作简单，外观吸引人

## 6. 风险评估

### 6.1 技术风险
- **设备连接**：网络不稳定可能影响设备连接
- **AI 准确性**：AI 情绪识别和任务拆解的准确性可能不够理想
- **系统集成**：各模块之间的集成可能存在问题

### 6.2 用户风险
- **儿童接受度**：儿童对设备的接受度和使用频率可能不高
- **家长参与度**：家长的参与度和使用习惯可能影响系统效果
- **数据隐私**：儿童数据的隐私保护需要特别关注

### 6.3 解决方案
- **设备连接**：实现离线工作模式，确保设备在网络不稳定时仍能正常工作
- **AI 准确性**：持续优化 AI 模型，提高识别和拆解的准确性
- **系统集成**：加强测试，确保各模块之间的无缝集成
- **儿童接受度**：设计有趣的游戏化元素，提高儿童的使用兴趣
- **家长参与度**：提供清晰的数据和实用的功能，提高家长的参与意愿
- **数据隐私**：严格遵守数据隐私法规，保护儿童数据安全

## 7. 项目范围

### 7.1 包含范围
- **硬件终端**：ESP32-S3 驱动的实体玩偶，支持专注模式、任务提醒、NFC 互动
- **移动端 App**：儿童端和家长端，支持任务管理、奖励系统、情绪管理、数据分析
- **管理后台**：用户管理、数据大盘、Prompt 模板管理
- **AI 中台**：任务拆解、情绪分析、智能推荐

### 7.2 排除范围
- **第三方集成**：暂不支持与其他育儿应用的集成
- **高级 AI 功能**：暂不支持高级的情绪识别和行为预测
- **硬件扩展**：暂不支持除 NFC 贴纸外的其他硬件扩展
- **多语言支持**：暂不支持多语言界面

## 8. 总结

Small Steps 系统是一个针对 ADHD 儿童的行为习惯辅助系统，通过 AI 极简拆解、实体玩偶锚点和 CBT 专家系统的结合，为 ADHD 儿童和他们的家庭提供有效的行为习惯辅助方案。本需求规约详细定义了系统的功能需求、非功能需求、数据需求和验收标准，为系统的设计、开发和测试提供了明确的依据。通过严格按照本规约执行，可以确保系统能够满足用户的需求，为 ADHD 儿童的成长和发展提供有力的支持。
