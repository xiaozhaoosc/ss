**页面**: 登录页

**复现步骤**:

3. 检查本地存储

**严重程度**: P1  
**页面**: 任务创建  
**状态**: open

**描述**:

**复现步骤**:
1. 填写任务信息

3. 观察页面状态

**影响的测试用例**:
- TC-P-TASK-003
