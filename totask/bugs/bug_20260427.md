## Bug #1 - UniApp 遮罩层拦截底部导航栏点击

- **严重程度**: 高

### 问题描述
在家长中心页面，底部导航栏被 UniApp 的遮罩层（uni-mask）遮挡，导致无法点击底部导航栏进行页面切换。

### 复现步骤
1. 使用家长账号登录系统
2. 导航到家长中心页面 (/pages/parent/profile/index)
3. 尝试点击底部导航栏的"首页"按钮

点击底部导航栏应该跳转到对应的页面。

### 实际行为
底部导航栏被 uni-mask 遮罩层遮挡，点击事件无法触发，控制台显示：
```
<div class="uni-mask"></div> from <div id="u-a-m" data-v-app="">…</div> subtree intercepts pointer events
```

## 技术分析

### 根本原因
UniApp 框架在 H5 模式下，底部导航栏（bottom-nav）组件上方会创建一个 `uni-mask` 遮罩层，该遮罩层拦截了所有下层元素的点击事件。

### 遮罩层结构
```html
<div id="u-a-m">
  <div class="uni-mask"></div>  <!-- 遮罩层 -->
  <div id="app">
    <!-- 实际页面内容 -->
    <bottom-nav mode="parent" />
  </div>
</div>
```

### 可能的影响因素
1. **Z-index 问题**: 遮罩层的 z-index 可能高于底部导航栏
2. **组件加载顺序**: bottom-nav 组件可能在遮罩层之后渲染，但 z-index 较低
3. **CSS 样式冲突**: 遮罩层的样式设置可能导致pointer-events 被错误地应用

### 建议的解决方案
1. 检查 bottom-nav 组件的 z-index 设置
2. 确保底部导航栏的 z-index 高于遮罩层
3. 检查是否有全局样式覆盖了 pointer-events 属性
