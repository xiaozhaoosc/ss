# 工作流: 自动化技术文档归档

## 步骤 (Steps)
1. **识别候选文件**: 扫描项目根目录及 `docs/` 下匹配 `plan*`, `walkthrough*`, `*报告*` 的文件。
2. **获取时间戳**: 使用 `run_command` 或当前系统时间获取 `YYYYMMDDHHMM` 字符串。
3. **创建目标目录**: 
   ```bash
   // turbo
   mkdir -p archive/$(date +%Y%m%d)
   ```
4. **执行移动/复制**: 对每个文件重命名并存入目标目录。
   - 命名格式: `[原名]_%Y%m%d%H%M_%NN.md`
5. **记录日志**: 在 `演示报告` 中提及本次归档结果。

## 适用场景
- 任务完成阶段
- 交付成果确认前
- 用户明确要求“保存”时
