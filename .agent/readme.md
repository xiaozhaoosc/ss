# Agent 核心配置目录 (.agent)

本目录存储 Google Antigravity Agent 的核心配置文件、上下文定义及自动化工作流。

## 目录结构

- **workflows/**: 存放自定义工作流 (`.md` 文件)。
    - `human30.md`: **Human 3.0 中文原生协议**。定义了协作的核心准则、语言规范及本质主义哲学。
    - `autoTests.md`: **自动化测试工作流**。基于 Playwright 实现自动化 UI 遍历与用户手册生成。
- **context.md**: 项目级业务上下文。Agent 在启动任务时会优先读取此文件以理解业务背景。
- **rules/**: (可选) 存放具体的 Prompt 规则或约束。

## 如何使用

### 1. 协议激活
Agent 会通过读取 `context.md` 自动加载 `human30.md` 协议。你无需手动操作。
若需强制复位，可发送指令：
> “遵循 /human30 协议”

### 2. 运行工作流
在对话中直接引用工作流路径或名称：
> “运行 /autoTests”

## 维护指南
- 所有 `.md` 文件均应使用 **UTF-8** 编码保存。
- 修改工作流后，无需重启 Agent，新的对话交互即可生效。
