# “小步 (Small Steps)” 功能设计方案：艺术课 & 游戏时间

这两项功能出现在“任务完成”后的界面，其核心本质不是“额外的作业”，而是 **“正向激励 (Positive Reinforcement)”** 与 **“情绪调节 (Emotional Regulation)”** 的载体。

## 1. 核心设计哲学

*   **艺术课 (Art Class)**：**非评价性的自我表达**。ADHD 儿童常因“做错”被纠正而焦虑。这里的艺术课应强调“过程”而非“结果”，提供一个无压力的创造空间。
*   **游戏时间 (Game Time)**：**受控的多巴胺释放**。ADHD 儿童极易在游戏中产生“过度沉浸 (Hyperfocus)”。设计重点在于“有尊严的结束”和“从屏幕/设备回到现实的过渡”。

---

## 2. 详细设计：艺术课 (Art Class) - “随心画/随心创”

### A. 产品逻辑 (PM Perspective)
*   **目标**：通过触觉、视觉的创造，降低多巴胺剧烈波动后的戒断感。
*   **机制**：
    *   **AI 灵感库**：提供简单的、不具象的提示词（如“画一个快乐的圈圈”、“今天的风是什么颜色？”）。
    *   **即时上墙**：完成的作品可以一键发送到家长的“情绪日报”或 App 的“作品墙”。
*   **体现原则**：*儿童尊严优先* —— 只有赞美和记录，没有评分。

### B. 硬件交互 (ESP32 - 128x160)
*   **屏幕方案**：
    *   **像素画模式 (Pixel Art)**：由于屏幕分辨率低，直接做自由绘画体验差。采用 16x20 的网格像素画。
    *   **按键逻辑**：
        *   `Up/Down/Left/Right` (Up/Down切换，OK确认位置/选色) —— *由于只有4个键，建议采用“摇摆选色+确定移动”的简化流*。
    *   **灯光辅助**：WS2812B 灯环显示当前选中的画笔颜色。

### C. App 交互 (UX Perspective)
*   **儿童端**：提供更丰富的绘图工具，支持手写笔，支持“魔法变幻”（将简单的涂鸦通过 AI 转变为精美插画）。
*   **家长端**：收到“艺术作品”提醒，引导家长点击“点赞”并发送一段语音鼓励（推送到硬件端）。

## 3. 详细设计：游戏时间 (Game Time) - “能量释放/专注挑战”

### A. 产品逻辑 (PM Perspective)
*   **目标**：提供高质量的娱乐，同时训练抑制控制能力。
*   **机制**：
    *   **倒计时沙漏**：严格的时间限制，但采用“柔性结束”机制。
    *   **游戏类型建议**：
        1.  **物理交互游戏**：如“木头人”（利用 ESP32 加速度计检测震动）。
        2.  **反应力挑战**：灯环闪烁特定颜色时按下 OK。
*   **体现原则**：*拥抱失败* —— 游戏失败不扣分，只是“能量耗尽，明天再来”。

### B. 硬件交互 (ESP32 - 1.8" Screen)
*   **屏幕方案**：
    *   **动态能量条**：用占据半个屏幕的能量条代替冷冰冰的数字倒计时。
    *   **UI 示意**：
        ```text
        +----------------+
        |   GAME ON!     |
        |     [o.o]      |
        |  [=========  ] | <--- 能量条
        |   Time: 05:00  |
        +----------------+
        ```
*   **防沉迷灯语**：
    *   剩余 1 分钟：灯环变为黄色呼吸。
    *   结束：灯环变为紫色渐灭（柔和降温），而非突兀熄灭。

### C. 交互哲学：有尊严的结束 (The Exit Ritual)
*   **痛点**：ADHD 儿童在游戏结束时最易爆发情绪。
*   **设计**：游戏结束时，设备不是冷酷地黑屏，而是说：“你刚才的反应力简直像超人！现在我们需要给小步充电了，帮它盖上被子吧（放置到特定位置/NFC感应）。”

## 4. 下一步行动建议 (Shadow Observer)

1.  **[NEW] 页面创建**：在 `src/pages/child/` 下创建 `art-class` 和 `game-time` 目录。
2.  **[MOD] 路由配置**：在 `pages.json` 中注册新页面。
3.  **[ESP32] 通信协议**：定义 BLE 或 MQTT 指令，由 App 触发硬件进入对应的艺术/游戏状态（同步灯效）。
