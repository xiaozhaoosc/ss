# Small Steps 项目编年史 (CHRONICLE)

## [2026-04-28] UniApp H5 交互兼容性专项治理
- **事件**: 彻底解决了长期困扰 H5 环境的 `uni-mask` 点击拦截 P0 级问题，并优化了多端导航栏冲突。
- **决策**: 
  1. **防御性 CSS 架构**: 引入了基于 `pointer-events` 的全局遮罩层治理方案，将原本“一刀切”的阻断式交互改为“按需阻断”，极大提升了系统的容错能力。
  2. **端侧隔离优化**: 在 `App.vue` 生命周期中增加了 H5 特有的 `uni.hideTabBar()` 强制执行逻辑，消除了原生组件对自定义 UI 的底层干扰。
- **影响**: 解决了多份 Bug 报告中提到的“页面卡死”假象，显著降低了用户的心理压力，符合“Cognitive Ease”的核心设计准则。

## [2026-04-10] 项目重启与 ADHD 组件重构
- **事件**: 针对 smallsteps-ui 模块中遗失的 ADHD 管理组件进行紧急恢复。
- **背景**: 发现部分旧代码未提交至 Git，导致前端界面缺失核心业务逻辑。
- **决策**: 放弃寻找“丢失”的代码，基于后端 VO 和领域模型直接在 `smallsteps-ui/src/views/smallsteps/` 目录下重新构建高质量的 ADHD 专用管理组件。
- **影响**: 确保了 V6 学术版本的 UI 一致性与逻辑正确性。

## [2026-04-12] AI 智能路由与轻量化审批决策
- **背景**: 硬件资源与 API 配额受限，需确保 AI 服务的高可用；同时需要一套不依赖复杂 BPMN 引擎的审批流程。
- **决策**: 
  1. 开发 `SmartAiClient`，实现 GLM > Kimi > Llama 的权重 Failover 逻辑。
  2. 建立 `ss_parent_reward_redemption` 表，通过同步 Service 调用实现“申请-审批-分发”的轻量化业务流程。
- **影响**: 系统鲁棒性大幅提升，业务逻辑实现闭环，研发效率提升。

## [2026-04-13] 自动化测试与质量保障

## [2026-04-24] [Feature] 全链路需求闭环与 ADHD 干预增强
- **事件**: 对照《需求文档.md》完成了任务拆解执行、奖励审批契约、个性化头像等核心缺失模块的补全。

- **影响**: 标志着“Small Steps”系统正式完成从“任务列表”到“闭环行为干预平台”的跨越。
