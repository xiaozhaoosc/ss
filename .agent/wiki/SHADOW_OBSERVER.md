# 影子观察者 (Shadow Observer) 功能待实现列表

> [!NOTE]
> “影子观察者”是 Small Steps 系统中的一个核心概念，旨在以“不打扰、不监控”的方式，通过感知孩子在物理设备和 App 上的交互行为，为家长提供深层的情绪洞察和行为引导。

- [x] **全局高响应交互**:
    - [x] 针对所有 `Button` 和 `List Item` 实现基于 `hover-class` 的即时视觉反馈（StatCard, BottomNav, TemplateCard）。
    - [x] 优化移动端点击延迟，确保交互响应在 100ms 以内（Shadow Fast-track）。
- [ ] **物理感交互反馈**:
    - [ ] 配合硬件终端，实现“屏幕+灯光”的协同反馈（V2 计划）。

## 5. 硬件端交互规格 (Hardware Interaction - 4 Buttons)

针对 1.8 寸屏幕与 4 个物理按键 (Up/Down/OK/Back) 的影子观察逻辑：

### A. 专注模式 (Focus Mode) 的“光语”与“声语”
- **呼吸灯 (WS2812B)**:
    - `专注中`: 蓝色低频呼吸（0.1Hz），减少视觉干扰.
    - `任务即将结束 (最后5分钟)`: 橙色渐强呼吸。
    - `超时警报`: 红色双闪 + 轻微震动。
- **音效提示**:
    - `开始`: 清脆的“叮”声（上升调）。
    - `完成`: 欢快的八音盒旋律（3秒）。

### B. 物理按键的影子监测
- **OK 键长按 (SOS/求助)**:
    - 任何界面长按 OK 键 3 秒，上报“孩子可能需要帮助”预警。
- **Back 键误触保护**:
    - 任务进行中按下 Back，屏幕显示像素风“真的要放弃吗？”提示，需 OK 确认，影子观察者记录此次“意图放弃”。

## 6. 伦理与隐私红线 (Ethics & Privacy)
- **数据本地化**: 所有影子观察的“密集点击”和“长按”行为，先在设备端进行初步过滤，仅上报“异常摘要”而非原始全量点击流。
- **家长可见性**: 家长端需明确标识哪些数据是“影子观察”推测出的，哪些是孩子主动提交的。

## 7. 系统稳定性与闭环验证
- [ ] **核心流闭环验证**: 自动化验证奖励兑换从“发起”到“审批”再到“余额变动”的完整闭环。
- [ ] **数据隐私隔离**: 影子观察数据仅保存在 `ss_emotion_record` 且仅对授权家长可见。
