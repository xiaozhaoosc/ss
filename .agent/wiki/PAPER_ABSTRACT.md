# 毕业设计（论文）自述与核心要点沉淀

## 1. 论文自述部分 (300～500字)

本课题针对ADHD（注意缺陷与多动障碍）儿童研发了“Small Steps（小步）”行为习惯辅助系统，创新性地构建了“软硬协同+混合智能干预”的数字化康复路径。

系统围绕“认知极简与情感温润”的双端心智交互展开：儿童端通过糖果风矢量装扮、轻弹簧物理动效（如 `@keyframes hatBounce`）和高容错物理按钮提供即时正向激励，并利用防儿童误触的“家长之门”两位数乘法验证保障打卡沉浸感；家长端则提供冷静理性的离线 SVG 矢量多维数据洞察看板。技术层面上，设计了基于 PostgreSQL 关键词与 SimpleVectorStore 向量检索的双路多源混合检索（Hybrid Retrieval）AI 情绪分析引擎，用于安全解析儿童的树洞倾诉，为家长生成富有心理抚慰意义的温情洞察。系统底层采用 Spring Boot 3 + Sa-Token 强力保障双端权限隔离，并通过 Pinia 深度监听、动态组件 key 重置与 alias 路由自愈等机制，实现高健壮性的前端交互自愈。本设计不仅是一次前后端全栈工程实践，更是用技术赋能 ADHD 儿童，帮助其将外部辅助转化为自主习惯，重塑家庭的良性动力学关系。

---

## 2. 论文核心要点梳理 (技术与业务亮点)

### 💡 核心要点一：基于“认知极简与情感温润”的双心智交互系统
*   **儿童端交互哲学**：ADHD儿童极易受到界面杂音的干扰。系统摒弃了冷冰冰的数字进度条与复杂的输入框，代之以糖果风本地矢量切图与基于 `@keyframes hatBounce` 的物理掉落弹性换装动效。
*   **“家长之门”拦截**：在儿童端前往设置与切回家长端时，引入动态两位数乘法算术题校验，保护儿童独立打卡心智。
*   **家长端冷静设计**：完全剔除外部不稳定 Google Material Symbols 字体，全量采用 Inline SVG 原生图标进行 100% 离线自愈重构，大幅降低网络波动导致的用户认知负荷。

### ⚡ 核心要点二：PostgreSQL + VectorStore 双路混合检索的 AI 情绪引擎
*   **混合检索架构 (Hybrid Retrieval)**：设计了基于 PostgreSQL 关键词匹配与 `SimpleVectorStore` 语义向量检索的双路合并算法。能够从 ADHD 儿童每日在硬件/APP端的“树洞倾诉”中，精准匹配本地心理学微干预知识库，合成极高置信度的上下文。
*   **大模型鲁棒解析与空安全防御**：针对深度思考大模型输出中的 `<think>` 思考标签，在 `AiServiceImpl` 层设计了精准的正则过滤与异常拦截，结合 MapStruct VO 空集合兜底机制，从根本上杜绝了接口解析崩溃风险。

### ⚙️ 核心要点三：前后端全链路自愈与权限隔离机制
*   **Pinia 深度监听自愈**：利用 `watch` 响应式追踪，解决单页应用（SPA）在浏览器直接刷新（F5）时 Pinia 异步状态恢复延迟、导致首屏数据变空的顽疾。
*   **动态 Key 重置幽灵状态**：为任务卡片引入动态版本版本印记，解决 Vue 虚拟 DOM 复用机制在 `onShow` 数据刷新时保留专注模式幽灵状态的问题。
*   **权限与别名路由兼容**：基于 Sa-Token 鉴权框架，允许儿童角色在 `@SaCheckLogin` 下安全调用通用的图片反馈上传接口，配合后端 `@GetMapping` 路由 Alias 注解兼容，实现 100% 健壮的数据闭环。
