# 📝 小步 (Small Steps) 影子观察者系统：功能清单与测试规范 (2026-04-28)

## 一、 今日功能开发清单 (Feature Checklist)

### 1. 儿童端：多维行为感知 (Behavioral Perception)
- [x] **高频点击感知 (Agitation Detection)**：实现了 2 秒内点击次数超过 6 次的“躁动”行为识别算法。
- [x] **触觉反馈增强 (Tactile Feedback)**：为所有交互按钮新增 `hover-class` 缩放反馈，提升 ADHD 儿童的操作确认感。
- [x] **静默情绪上报 (Silent Reporting)**：自动将识别出的“挫败感 (Frustrated)”行为打标并异步持久化至 `ss_emotion_record` 表。

### 2. 后端：影子洞察引擎 (Insight Engine)
- [x] **情绪统计聚合 API**：新增 `/parent/insight/emotion/shadow-trend` 接口，支持按天计算：
    - 每日平均情绪值 (`avgMood`)。
    - 每日挫败行为总次数 (`frustrationCount`)。
- [x] **数据隔离与鉴权**：在 `ParentInsightController` 中集成了 `checkChildAccess` 校验，确保家长只能访问所属家庭儿童的预警数据。

### 3. 家长端 (App)：情绪预警看板
- [x] **趋势柱状图**：使用颜色编码（绿/蓝/黄/红）展示每日情绪稳定性。
- [x] **预警胶囊 (Warning Capsule)**：在柱状图顶部直观显示当日被影子系统捕捉到的“挫败事件”次数。

### 4. 管理端 (Web UI)：深度联调图表
- [x] **散点预警序列**：在“守护洞察”折线图中新增“影子预警”散点层。
- [x] **呼吸感图标**：使用红色三角形警示图标并辅以发光动效，实现“任务负荷-情绪稳定性-影子预警”的三维关联分析。

## 三、 质量评估与建议 (QA Insights)
1.  **数据延迟**：当前采用即时上报，若网络不稳定可能导致预警点滞后。建议在 V2 中加入前端缓存及断点续传机制。
2.  **阈值调优**：目前的“2秒6次”为初步经验值。建议后续根据 `DEBT_LEADGER.md` 中的记录，根据不同年龄段儿童的点击速度进行动态阈值适配。
