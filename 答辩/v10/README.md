# V10 版本说明

## 📁 文件结构

```
答辩/v10/
├── 论文_v10.md          # V10版本的论文（AIGC优化版）
├── 论文_v10.docx        # 已转换的 Word 文档
├── md2word.py           # Python转换脚本
├── convert_v10.bat      # Windows批处理转换脚本（双击运行）
└── README.md            # 本说明文件
```

## 🎯 V10版本目标

- **AIGC检测率**：从73%降至20%以下
- **保持学术性**：避免过度口语化
- **最小化修改**：仅针对高风险AIGC区域

## 📊 修改策略

### 高优先级修改区域（占比最高）

1. **摘要部分**（片段1-3）
   - 打破"随着...的发展"模板句式
   - 加入"基于此背景"等限定词
   - 使用"本系统的一个特色在于"替代"核心创新在于"

2. **绪论/文献综述**（片段4-10）
   - 使用"较为常见"替代"最为常见"
   - 简化长句，增加"在此背景下"等过渡词
   - 打破"一方面...另一方面..."对称结构

3. **技术选型**（片段11-12）
   - 使用"较好的适配性"替代"更好的适配性"
   - 简化框架描述，避免模板化

4. **章节引言/小结**（片段13-20）
   - 移除"系统性"等修饰词
   - 使用"明确的约束条件"替代"清晰的约束条件"

### 降重原则

- ✅ 保持专业学术性
- ✅ 打破模板化句式
- ✅ 加入个人视角限定词
- ❌ 避免过度口语化
- ❌ 避免使用"data stuff"等非学术表达

## 🚀 使用方法

### 方法一：双击批处理文件（推荐）

直接双击 `convert_v10.bat` 文件即可自动转换。

### 方法二：手动运行Python脚本

```bash
cd 答辩/v10
python md2word.py
```

### 方法三：安装依赖后运行

```bash
# 安装依赖
pip install python-docx

# 运行转换
python md2word.py
```

## 📝 段落与换行处理

Python脚本会自动处理以下内容：

1. **段落分隔**：空行自动分隔为新段落
2. **代码块**：使用灰色背景和等宽字体
3. **表格**：自动转换为Word表格
4. **列表项**：使用项目符号样式
5. **标题层级**：自动设置不同字号
6. **分隔线**：转换为水平线
