# V1 版本说明

## 文件说明

- `论文_v1.md` - 基于原文进行最小化修改的版本
- `论文_v1.docx` - 已转换的 Word 文档
- `convert_v1.bat` - Windows 批处理转换脚本（双击运行）
- `README.md` - 本说明文件

## 修改策略

V1 版本采用**最小化修改策略**，针对 AIGC 检测报告中标记为高风险的区域进行修改：

### 主要修改内容：

1. **摘要部分**（中文和英文）
   - 打破"随着...的发展"模板句式
   - 加入"基于此背景"等限定词
   - 将"本研究的创新点在于"改为"本系统的一个特色在于"

2. **绪论引言**
   - 减少"显著"、"颇为"等绝对化表述
   - 使用"较为常见"替代"最为常见"
   - 增加"在此背景下"等过渡词

3. **研究背景**
   - 简化长句结构
   - 使用"较弱"、"不足"等相对表述
   - 增加"较为明显"等限定词

4. **研究目的**
   - 打破"一方面...另一方面..."对称结构
   - 使用"逐渐显现"替代"日益凸显"
   - 增加"让不少家长有所顾虑"等表述

5. **文献综述**
   - 简化"近年来...逐渐成为..."句式
   - 使用"一个热点方向"替代"热点方向"

6. **技术选型**
   - 使用"被广泛应用于各类项目"替代"当前主流的技术选型"
   - 简化框架描述
   - 使用"较好的适配性"替代"更好的适配性"

7. **章节小结**
   - 移除"系统性"等修饰词
   - 使用"明确的约束条件"替代"清晰的约束条件"

## 使用方法

### 方法一：双击批处理文件

直接双击 `convert_v1.bat` 文件即可自动转换。

### 方法二：手动运行 PowerShell 脚本

打开 PowerShell，执行：

```powershell
cd "答辩/v1"
pandoc -f markdown -t docx --toc --highlight-style=tango "论文_v1.md" -o "论文_v1.docx"
```

### 方法三：直接使用 pandoc 命令

```bash
pandoc -f markdown -t docx --toc --highlight-style=tango 论文_v1.md -o 论文_v1.docx
```

## 输出文件

转换完成后，会在当前目录生成 `论文_v1.docx` 文件。

## 注意事项

1. 确保已安装 pandoc（下载地址：https://pandoc.org/installing.html）
2. 生成的 docx 文件包含自动生成的目录（TOC）
3. 如需更新目录，请在 Word 中右键点击目录 -> "更新域"

## AIGC 检测建议

V1 版本已对高风险区域进行修改，但仍建议：

1. 转换后再次进行 AIGC 检测
2. 根据检测结果，对仍被标记的区域进行针对性修改
3. 保持专业学术性的同时，适当增加个人视角表述
