5 系统测试

任何软件系统在交付用户之前都需要经过系统性测试，对于"小步"而言这一点尤其重要——目标用户是儿童，数据涉及健康隐私，系统稳定性和安全性方面的问题容错空间很小。本章描述测试环境的搭建方案、各维度的测试策略，以及实际运行结果。

5.1 测试环境与策略构建

5.1.1 测试环境说明

测试采用独立的预发布环境，而非直接在开发机上进行。后端服务通过Docker容器化部署PostgreSQL 15数据库与Redis 7缓存，保证与生产环境的隔离性。移动端编译为H5网站，分别在PC浏览器、华为P40 Pro与Mate 30 Pro设备上完成兼容性验证，总体未发现明显适配问题（有一处刘海屏状态栏的padding需要手动调整）。管理后台通过Chrome最新版浏览器访问测试。

5.1.2 测试维度设计

本次测试从三个维度展开：

功能逻辑验证：从家长创建任务开始，经儿童接收、专注执行、打卡完成，到AI反馈生成，验证整条业务链路的完整性与连贯性，排查数据断点或状态异常。

交互体验验证：模拟各类用户操作场景，检测按钮响应、页面跳转、倒计时切换后台后再恢复等交互环节的稳定性。该维度采用Playwright自动化测试框架，覆盖管理后台UI（17个用例）与H5移动端（62个用例），共79个自动化测试用例。

性能压力验证：对核心接口进行并发压力测试，验证打卡接口响应时间（P99 < 150ms）、登录接口并发承载能力（QPS ≥ 1000）等非功能指标是否满足设计要求。


5.2 核心业务功能测试

5.2.1 多角色权限与路由测试

本节主要验证Sa-Token权限隔离机制的实际效果。

横向越权测试：使用儿童账号的Token，构造POST请求尝试访问家长端的任务创建接口。后端返回403，提示权限不足，注解拦截机制正常生效。

纵向越权测试：使用家长A的Token，尝试查询家长B名下儿童的数据。后端返回空数组，底层数据隔离拦截器正常工作，未允许跨家庭的数据访问。

Sa-Token与自定义拦截器的组合在权限隔离方面表现符合预期。

5.2.2 任务生命周期状态扭转测试

本节验证任务从创建到完成的状态变迁与数据落库的正确性。

具体操作过程：创建一条"限时5分钟"的扫地任务。儿童端刷新后可见对应卡片，状态为待办（status=0）。进入专注模式后数据库状态变更为执行中（status=1）。测试中将App切至后台挂起约30秒再切回，倒计时按自然时间差继续递减，未出现计时暂停或跳变问题。

倒计时结束后，系统自动播放完成音效并发起打卡提交，数据库中代币余额更新正确，与任务配置的奖励数额一致。整条链路状态流转与设计文档一致，数据回溯完整。

5.4 本章小结

本轮测试从功能逻辑、交互体验与性能压力三个维度对系统进行了全面验证。权限隔离方面，Sa-Token的表现符合预期，横向越权与纵向越权均被有效拦截。任务从创建到完成的状态流转顺畅，切后台恢复计时未出现异常，积分结算准确。性能方面，打卡接口P99延迟148ms（< 150ms），登录QPS达到1201（> 1000），核心指标全部达标。自动化测试79个用例经10轮迭代回归最终全部通过。系统整体稳定性与性能表现良好，核心业务流程均已通过验证。


6 总结与展望

当前社会节奏下，ADHD儿童群体在家庭教育场景中面临的困难被严重低估。为缓解这类家庭长期承受的监督耗竭困境，本研究设计并实现了"小步"双端行为习惯辅助协同系统。在研究与开发过程中，完成了以下几项核心工作：

确立了"低压力"的UI交互设计哲学。摒弃带有威慑感的界面风格，通过游戏化代币奖励与大语言模型生成的情感化话术构建干预闭环。

构建了前后端分离的现代化技术架构。后端基于Spring Boot 3与MyBatis-Plus搭建业务核心，Sa-Token实现灵活的多角色权限管控；前端基于UniApp 3.0实现多端覆盖，Vue 3的Composition API与Pinia提供高效的状态管理能力。

探索了AI赋能业务的工程路径。在完成基础信息交互功能的基础上，将大语言模型以异步旁路的方式嵌入后端定时流程，使系统具备一定的个性化反馈能力，并通过降级机制保证外部依赖故障不影响核心业务运行。


6.1 总结

项目实施过程中遇到了几个值得记录的工程问题：

初期因任务状态查询涉及多表关联，加上缺乏缓存设计，并发量稍高时后端响应明显变慢。引入Redis承担会话缓存与防重复提交的锁后，QPS从几百提升至千级，这个提升效果比预期要明显。

前端为实现ADHD儿童"零跳转、所见即所得"的体验目标，刻意精简了复杂的路由结构，依靠Pinia的全局状态与TailwindCSS的按需渲染作为替代方案。这样做的代价是组件间通信的耦合度稍有上升，但对最终用户的体验提升是值得的。

大模型集成方面，调用延迟和偶发的返回格式异常是两个主要问题。前者通过异步化解决，后者通过JSON解析容错与降级话术兜底处理，实测稳定性可接受。

6.2 系统存在的不足与未来展望

"小步"系统在实验室层面通过了功能与性能测试，核心架构也具备一定的扩展空间，但距离真正意义上的商业化产品还有一段距离。以下几个方向值得后续深入：

多模态数据的联动感知。当前行为数据来源仅限于用户主动打卡记录，信息维度单一。未来可考虑接入可穿戴设备的蓝牙数据，通过实时采集心率等生理指标客观评估儿童专注状态，形成多维度的数据验证，而不是单纯依赖主动行为记录。

本地化大模型部署（Edge AI）。为保护干预数据的隐私安全，同时规避第三方API的调用成本与稳定性风险，后续可探索在网关内网或边缘计算终端部署轻量化大语言模型，实现完全离线环境下的智能分析。

科学技术的价值不止于提升效率，更在于为那些不容易被关注到的群体建立平等的支持。"小步"是对神经多样性的一次具体回应，期待它有机会走进更多普通家庭，让每一位特别的孩子都能在自己的节奏下，迈出下一步。

 * LLM任务分解Prompt模板
 * Spring Boot后端服务中的Prompt构建逻辑

package com.adhd.assistant.ai.prompt;

import java.util.Map;

/**
 * 任务拆解系统角色Prompt模板
 */
public class TaskDecomposePromptTemplate {

    /**
     * 系统角色Prompt（System Prompt）
     */
    public static final String SYSTEM_PROMPT = """
        你是一位专业的ADHD（注意力缺陷多动障碍）儿童行为辅导专家。
        你擅长将复杂的日常任务拆解为ADHD儿童能够独立执行的极小步骤。

        ## 拆解原则

        1. 每个步骤必须是单一、具体、可立即执行的动作。
           错误示例："整理书包"（太笼统）
           正确示例："把数学课本放进书包"（具体可执行）

        2. 步骤数量控制在3到8个之间，过多会让孩子感到压力。

        3. 每个步骤的预计用时（duration_sec）应根据儿童年龄合理估算：
           - 6-8岁：每个步骤建议60-180秒
           - 9-12岁：每个步骤建议120-300秒
           - 13岁以上：每个步骤建议180-600秒

        4. voice字段（语音引导语）的语言风格要求：
           - 充满鼓励和温暖，使用儿童友好的语言
           - 每句话不超过30个字
           - 可以适当使用拟声词和感叹号增加趣味性
           - 避免使用否定词（如"不要""不能"），改用正面引导

        5. 步骤之间应有清晰的逻辑顺序，遵循时间线或空间线。

        6. 最后一个步骤应包含"完成确认"的正面反馈。

        ## 输出格式要求

        你必须且只能输出一个合法的JSON数组，不要包含任何其他文字说明。
        每个数组元素包含以下三个字段：
        - desc: 步骤描述（不超过20个字）
        - duration_sec: 建议用时（整数，单位：秒）
        - voice: 语音引导语（不超过30个字）
        """;

    /**
     * 用户Prompt模板（User Prompt）
     */
    public static final String USER_PROMPT_TEMPLATE = """
        请将以下任务拆解为适合ADHD儿童执行的微步骤。

        ## 任务信息
        - 任务名称：{task_title}
        - 儿童年龄：{child_age}岁
        - ADHD类型：{adhd_type}

        ## 输出要求
        请以JSON数组格式输出，每个元素包含desc、duration_sec、voice三个字段。

        ## 输出示例
        [
          {"desc": "把铅笔和橡皮放在桌面上", "duration_sec": 30, "voice": "先把铅笔和橡皮拿出来，放在桌上哦！"},
          {"desc": "打开数学课本翻到第12页", "duration_sec": 60, "voice": "找到数学课本，翻到第12页，你真棒！"}
        ]

        现在请拆解任务：{task_title}
        """;

    /**
     * 构建最终的用户Prompt
     */
    public static String buildUserPrompt(String taskTitle, int childAge, String adhdType) {
        String adhdTypeDesc = switch (adhdType) {
            case "I" -> "注意力不集中型（容易走神、遗忘）";
            case "H" -> "多动冲动型（坐不住、易冲动）";
            case "C" -> "混合型（兼具注意力不集中和多动冲动特征）";
            default -> "未指定";
        };

        return USER_PROMPT_TEMPLATE
                .replace("{task_title}", taskTitle)
                .replace("{child_age}", String.valueOf(childAge))
                .replace("{adhd_type}", adhdTypeDesc);
    }

    /**
     * JSON字符串转义工具方法

    private static String escapeJson(String input) {
        return input
                .replace("\\", "\\\\")
                .replace("\"", "\\\"")
                .replace("\n", "\\n")
                .replace("\r", "\\r")
                .replace("\t", "\\t");
    }
